# 防刷与访问安全

本区域显示设备频次、IP白名单、作答密码和验证码配置。当前运行支持存在链路差异，发布前应验证真实入口。

## 使用前提与入口

收集设置 → 答卷防刷与访问安全。

## 操作步骤

1. 如需密码，开启并填写非空密码，保存相关版本；当前公开页从链接参数传递密码，没有完整独立密码输入弹窗。
2. 配置设备一次、每日或间隔策略；自定义间隔可填1至720小时。
3. 启用IP限制后打开例外IP窗口，每行一个IP地址，点击完成并保存。
4. 验证码可保存进入前和提交时配置，但当前新答题页没有完整验证码核验流程。

## 按钮与设置

| 名称                   | 位置       | 作用与结果                    | 可用条件                 |
| ---------------------- | ---------- | ----------------------------- | ------------------------ |
| 设备作答频次           | 安全区域   | 保存 once／daily／custom 策略 | 自定义时显示小时数输入   |
| IP限制                 | 安全区域   | 保存IP限制开关                | 当前部署实际执行需验证   |
| 例外IP                 | IP限制右侧 | 编辑多行白名单                | 启用IP限制后显示         |
| 完成                   | 白名单窗口 | 关闭窗口，修改留在页面编辑态  | 等待自动保存完成         |
| 作答访问密码           | 安全区域   | 正式链路检查所给密码与配置    | 开启但密码为空将拒绝访问 |
| 进入前验证／提交时验证 | 验证码行   | 保存验证码开关                | 尚未完整接入新答题交互   |

## 结果与限制

设备控制不是可靠物理设备识别。清理浏览器、共享IP和代理都可能影响识别。旧兼容答题链有浏览器/IP处理，不代表新链路支持每日、间隔、白名单全部策略；不要用未验证开关保障唯一受访者。
