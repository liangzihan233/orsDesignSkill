# 外部对接与高级控制

BI、语言、复核等区域保留高级配置入口。当前多项只有配置与保存，实际答卷审核、备份和导出已由各自独立功能提供。

## 使用前提与入口

收集设置 → 外部系统对接／质检复核与高级控制。

## 操作步骤

1. 需要记录对接意图时开启BI并填写Webhook和未完成同步选项。
2. 选择语言种类并保存；不要假定会自动翻译问卷。
3. 查看其余高级开关，使用下表区分目前能力。

## 按钮与设置

| 名称                   | 位置     | 作用与结果                           | 可用条件                                   |
| ---------------------- | -------- | ------------------------------------ | ------------------------------------------ |
| BI实时推送／Webhook    | 外部对接 | 保存目标地址和开启状态               | 当前未接入可靠实时HTTP推送                 |
| 同步未完成答卷         | BI子设置 | 保存同步范围偏好                     | 不会因勾选即启动任务                       |
| 问卷语言种类           | 高级区域 | 保存简中、繁中、中英、英文、法文配置 | 不自动生成翻译；系统界面独立中英切换       |
| 发布后不允许模拟答题   | 高级区域 | 保存测试限制字段                     | 当前测试访问由凭证控制，不承诺本字段已执行 |
| 精确备用上限           | 高级区域 | 保存旧式备用开关                     | 实际容量按配额组目标与浮动量               |
| 启用人工复核／复核题号 | 高级区域 | 保存旧复核配置                       | 真实审核标签在结果数据独立操作             |
| 自定义结束代码支持     | 高级区域 | 保存高级开关                         | 外观脚本执行由独立样式配置决定             |
| 未完成数据与日志下载   | 高级区域 | 保存偏好                             | 结果Excel已支持ACTIVE未完成，日志页仍占位  |
| 关闭调试模式           | 高级区域 | 保存调试偏好                         | 当前未形成完整脚本构建开关                 |

## 结果与限制

不要把仅配置的BI地址视为已成功投递。审核不用先开启旧复核开关；导出未完成也不以这个高级开关为必要条件。外观自定义脚本会在公开页执行，属于另一个配置入口。
