# 附件上传与题库抽取

此处的附件控制与动态题库抽取目前主要保存配置。设计页从题库复制题目是真实能力，但不等于运行时自动随机抽题。

## 使用前提与入口

收集设置 → 附件上传控制／题库抽取设置。

## 操作步骤

1. 按需配置隐藏附件链接与单文件限制，保存后核对具体上传题运行表现。
2. 开启题库抽取，选择可重复／不可重复，填写数量及固定题号。
3. 如只需要复用题目，转到设计页题库面板选择题目复制。

## 按钮与设置

| 名称             | 位置       | 作用与结果             | 可用条件                     |
| ---------------- | ---------- | ---------------------- | ---------------------------- |
| 隐藏附件链接     | 附件控制   | 保存上传链接展示字段   | 当前上传组件未完整消费总控   |
| 只上传单个文件   | 附件控制   | 保存单文件限制字段     | 不能据此保证已执行           |
| 启用题库抽取     | 抽取区域   | 显示抽取策略输入       | 当前未接入动态组卷           |
| 可重复／不可重复 | 抽取子设置 | 选择数量对应的策略字段 | 按当前模式显示数量           |
| 固定题号         | 抽取子设置 | 保存英文逗号分隔题号   | 需有效题号，但目前不触发组卷 |
| 立即执行抽题     | 抽取区域   | 当前仅显示成功提示     | 不会调用真实抽题任务         |
| 重置抽题设置     | 抽取区域   | 清空本地抽取配置       | 自动保存完成后持久化         |

## 结果与限制

上传题组件本身有真实上传流程，但这些总控未形成完整执行链。不要把“立即执行抽题”的提示当成后台生成新试卷或题序已经变化。

## 每道题的附件材料

需要给填空、选择等题增加可实际上传的补充材料时，在设计页“基本属性 → 题目附件”配置。该入口已接入上传、校验、同会话草稿及提交，单文件最大 100MB；与这里尚未完整生效的附件总控分别使用，详见[题目附件](http://design.ors-cn.com/agent-help/articles/design/properties/attachments.md)。
