# 答题过程体验

过程体验控制返回与欢迎入口，同时保留若干旧版流程配置字段。

## 使用前提与入口

收集设置 → 答题过程体验与控制。

## 操作步骤

1. 按需允许返回上一页，配置最多返回1至50页。
2. 需要直接答题时开启跳过欢迎，但先检查隐私与签名要求。
3. 查看其他开关的保存效果，区分已执行与仅配置。
4. 以整页、一页一题或对话模式分别测试实际导航。

## 按钮与设置

| 名称                         | 位置       | 作用与结果                     | 可用条件                       |
| ---------------------------- | ---------- | ------------------------------ | ------------------------------ |
| 允许返回上一页               | 体验区域   | 控制返回按钮与历史页范围       | 开启后显示最大页数             |
| 最多返回                     | 返回子设置 | 限制从到达的最远页向前返回范围 | 1至50页                        |
| 跳过欢迎页                   | 体验区域   | 满足安全前提时直达答题         | 隐私不显示且不要求阅读／签名   |
| 禁止复制                     | 体验区域   | 保存防复制字段                 | 当前未见完整复制、右键拦截执行 |
| 错误不滚动到顶部             | 体验区域   | 保存错误导航偏好               | 当前主要为配置                 |
| 合页跳转不显示目标题号       | 体验区域   | 保存合页展示偏好               | 当前主要为配置                 |
| 手机合页逐题校验             | 体验区域   | 保存移动校验偏好               | 当前主要为配置                 |
| 隐藏图片放大／全部／部分题号 | 体验区域   | 保存放大控制及题目列表         | 当前主要为配置                 |

## 结果与限制

跳过欢迎不能绕过协议和签名。未设置返回限制的历史问卷可能按兼容默认允许返回，页面开关显示与旧值默认需要实测。其他开关不应被作为可靠反复制或实时质检保证。
