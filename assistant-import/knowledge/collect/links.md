# 收集链接与二维码

收集链接通过公共短码打开问卷，可新建多个来源链接分别启停。二维码编码对应链接。

## 使用前提与入口

问卷工作室 → 问卷收集 → 收集链接。正式分发前先确认问卷正式发布且收集开放。

## 操作步骤

1. 选中默认链接，复制后在无设计权限的浏览器窗口测试。
2. 需要区分渠道时新增来源名称，确认后选择该来源。
3. 复制该来源链接或下载PNG二维码进行分发；下载图片以问卷名称命名。
4. 暂停某渠道时关闭对应来源，恢复时重新启用。

## 按钮与设置

| 名称               | 位置           | 作用与结果           | 可用条件                 |
| ------------------ | -------------- | -------------------- | ------------------------ |
| 新增来源           | 链接列表工具栏 | 创建具名来源链接     | 名称去空格后非空         |
| 选择来源卡片       | 链接列表       | 切换右侧当前分享链接 | 存在对应来源             |
| 复制链接           | 来源卡片       | 将公共链接写入剪贴板 | 浏览器允许剪贴板访问     |
| 打开链接           | 来源卡片       | 新窗口打开公开答题   | 问卷及来源状态允许访问   |
| 下载二维码         | 二维码区       | 下载对应链接PNG      | 二维码生成完成前禁用     |
| 关闭来源           | 来源卡片       | 确认后禁止该来源访问 | 不会删除已有答卷         |
| 启用来源           | 来源卡片       | 恢复该来源访问       | 仍受问卷整体状态限制     |
| 分享文案／其他页签 | 右侧分享区     | 查看分发说明         | 不代表系统已自动发送消息 |

## 结果与限制

不要手工用问卷编号拼接短链，使用系统生成的公共地址。停用来源与停止整卷收集分别生效；公开二维码不会自动给予设计权限。嵌入收集已移除；访问设置等邻近页目前是占位。

## 拼接链接参数

在某条链接右侧点击“拼接链接参数”，添加参数名与参数值，在最终链接预览中核对后保存。参数按来源链接分别保存，刷新仍保留；清空所有行并保存可移除参数。显示、复制、打开及下载二维码统一使用保存后的最终链接。取消或关闭窗口不改变链接。

每条链接最多 20 组参数，参数名去除首尾空格后不能为空、不能重复，最多 64 个字符；参数值可为空，最多 1000 个字符。为确保二维码可生成，整个参数段编码后最多 1800 个字符。系统会自动编码中文、空格、加号、与号等字符，不需要手工输入 `?`、`&` 或 `%`。

参数位于 Hash 路由内，例如 `/#/boyan/publicCode?channel=wechat&uid=123`。答题流程可读取自定义参数；参数不会改变问卷公开码、来源归属和发布状态。问卷身份、会话、预览、访问密码和答题用户标识等系统保留名称不能作为自定义参数使用。
