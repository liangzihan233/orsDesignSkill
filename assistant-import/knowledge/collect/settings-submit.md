# 提交后行为

提交后行为区域提供跳转网址、统计报告、答卷预览和社交分享开关。当前这些设置主要是保存字段，不能保证对应结束页能力已接通。

## 使用前提与入口

收集设置 → 提交后行为与反馈。

## 操作步骤

1. 按需保存跳转网址；只填写可信且完整的目标地址。
2. 查看报告、答卷预览和分享开关，核对真实结束页是否提供入口。
3. 需要判断答题结果时，到结果数据查看服务器状态。

## 按钮与设置

| 名称             | 位置       | 作用与结果         | 可用条件                     |
| ---------------- | ---------- | ------------------ | ---------------------------- |
| 自动跳转网址     | 提交后区域 | 保存开关及目标网址 | 启用时显示网址输入           |
| 允许查看统计图表 | 提交后区域 | 保存结果公开偏好   | 当前没有完整公开统计报表流程 |
| 允许预览答卷     | 提交后区域 | 保存答卷回看偏好   | 当前没有完整提交后回看入口   |
| 显示社交分享按钮 | 提交后区域 | 保存分享展示偏好   | 不代表已接入社交平台发送     |

## 结果与限制

公开结束页有独立的结束页跳转字段读取；当前收集设置网址不等于已经连接该字段。数据是否正式计入由完成／备份／筛选／配额满结果及类型决定。
