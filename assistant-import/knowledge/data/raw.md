# 原始数据

页面铺满导航下方的可用宽高，外层不留内边距；桌面与手机均不限制内容最大宽度。长内容保留滚动。

原始数据保留传统正式完成答卷列表及CSV导出。它与结果数据的全状态筛选和Excel不同。

## 使用前提与入口

答卷数据 → 原始数据。

## 操作步骤

1. 设置时间、IP、地区与来源条件，点击查询应用到当前列表。
2. 点击重置恢复列表默认筛选。
3. 需要完整状态与筛选导出时转到结果数据；传统CSV导出目前只传入来源条件。
4. 删除行前确认其会进入不可恢复的答卷回收站。

## 按钮与设置

| 名称                             | 位置       | 作用与结果           | 可用条件                       |
| -------------------------------- | ---------- | -------------------- | ------------------------------ |
| 时间／IP／地区／来源             | 页面筛选栏 | 设置待查询条件       | 点击查询后应用                 |
| 查询                             | 筛选栏     | 应用列表筛选         | 不自动改变数据                 |
| 重置                             | 筛选栏     | 清空待应用与当前筛选 | 回到第一页                     |
| 导出数据                         | 工具栏     | 下载传统CSV          | 正式完成口径；导出参数只带来源 |
| 删除                             | 数据行     | 确认后实际移入回收站 | 释放配额、不递补备份           |
| 查看                             | 数据行     | 当前仅提示后续支持   | 真正详情使用结果数据           |
| 导出题目编码／清空答卷／导入数据 | 工具栏     | 目前仅显示提示       | 不会执行相应真实任务           |

## 结果与限制

传统CSV不会保证应用列表中的日期、IP、地区筛选；需要当前筛选的全量Excel请使用结果数据。原始数据不显示测试、备份或未完成记录，不意味着这些答卷丢失。

公开分享页的“原始数据”使用统一答卷查询，可按答卷状态、版本、审核、时间和答案筛选，点击详情查看当前答卷的完整答案；不提供下载、删除或审核。
