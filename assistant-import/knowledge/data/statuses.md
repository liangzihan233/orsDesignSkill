# 答卷状态与统计口径

答卷有四个独立维度：正式／测试类型、答题结果、审核标签、存放状态。修改其中一个不会覆盖另一个。

## 使用前提与入口

答卷数据 → 结果数据；总览位于配额进度页面顶部。

## 操作步骤

1. 先选择存放状态，再按正式／测试和结果筛选。
2. 使用永久答卷编号定位，不要用当前表格行号代替。
3. 判断统计数时只计算有效存放的正式完成答卷。

## 按钮与设置

| 名称                 | 位置         | 作用与结果                   | 可用条件                 |
| -------------------- | ------------ | ---------------------------- | ------------------------ |
| 正式／测试           | 类型列及筛选 | 区分正式样本和测试样本       | 转测试保留原答题结果     |
| 未完成 | 结果列 | 作答中的进度，或整卷倒计时超时记录 | 超时即使未作答也保存；不能继续正常提交 |
| 答题完成             | 结果列       | 正常提交且服务器分配正式完成 | 正式有效记录计入普通统计 |
| 备份                 | 结果列       | 命中配额且进入浮动容量       | 不计普通正式完成数       |
| 被筛选 | 结果列 | 跳转逻辑的“结束答题”或筛选结束 | 保留已答内容，不占额 |
| 配额满 | 结果列 | 容量耗尽或跳转逻辑显式选择配额满 | 保存已有答案，不计完成 |
| 已审核／未审核       | 审核列       | 独立人工标签                 | 不改变类型、结果、配额   |
| 有效／回收站／已删除 | 存放状态     | 控制可操作、可查询和保留范围 | 回收站和已删除只读       |
| 历史状态未知         | 历史结果显示 | 原结果无法恢复的旧作废记录   | 不能猜作完成或筛选       |

## 结果与限制

普通统计、问卷答卷总数、原始数据和其导出只计ACTIVE正式COMPLETED。结果页可以查五类及存放状态；结果Excel只导出ACTIVE匹配记录，可含测试及全部五类。答卷编号稳定不复用；PersonID当前通常为空。

## 提前成功与超时

跳转逻辑的“成功完成”会提交已有答案并进行真实配额分配，最终可能是答题完成、备份或配额满；“结束答题”和显式“配额满”不占配额。整卷超时则保存未完成，不等同于这三种结束动作。写入终态后，迟到的进度请求不会把记录恢复为未完成。
