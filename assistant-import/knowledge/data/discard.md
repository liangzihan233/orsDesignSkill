# 废弃答卷与保留期限

废弃可选择转入测试或移入回收站。操作保留原答题结果和审核标签；正式占额会释放，但备份不会自动补位。

## 使用前提与入口

结果数据：勾选有效行后废弃，或使用按编号废弃入口。

## 操作步骤

1. 选择目标答卷，或填写本问卷永久数字编号列表。
2. 选择转测试或回收站；可填废弃原因，最多1000字。
3. 先点击预览，核对匹配数量、缺失编号和不可处理数量。
4. 确认预览符合预期后点击确认废弃；更改目标、编号或原因需重新预览。
5. 刷新列表，用对应类型或存放状态查找结果。

## 按钮与设置

| 名称       | 位置       | 作用与结果                           | 可用条件                       |
| ---------- | ---------- | ------------------------------------ | ------------------------------ |
| 废弃所选   | 结果工具栏 | 处理勾选的ACTIVE记录                 | 至少有可处理记录               |
| 按编号废弃 | 结果工具栏 | 按永久编号定位本问卷答卷             | 使用正整数编号，不能用表格行号 |
| 转入测试   | 废弃窗口   | 改变正式／测试类型，保留原结果与审核 | 仅当前问卷有效记录             |
| 移入回收站 | 废弃窗口   | 改变存放状态并记录废弃时间           | 不可恢复                       |
| 废弃原因   | 窗口文本框 | 保存原因供查看和导出                 | 选填，最多1000字符             |
| 预览       | 窗口底部   | 只核对匹配与资格                     | 不执行废弃                     |
| 确认废弃   | 预览后底部 | 重新校验后实际执行                   | 没有匹配项时禁用               |
| 取消       | 窗口底部   | 关闭窗口不执行                       | 不限                           |

## 结果与限制

回收站不可恢复。满30天后按小时清理任务删除答案、关联信息、附件和个人数据，保留编号、类型、原结果、审核及时间等最小记录；失败可重试。共享引用的附件保留。转测试与废弃释放额后，新答卷可填空缺，当前备份不自动递补；配额规则或启停变化仍可能重新分类。
