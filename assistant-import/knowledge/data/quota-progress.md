# 配额进度与答卷总览

页面铺满导航下方的可用宽高，外层不留内边距；桌面与手机均不限制内容最大宽度。长内容保留滚动。

配额进度顶部显示答卷总览，无配额问卷也可查看；下方按激活版本展示普通与交叉配额的正式收取、备份及状态。

## 使用前提与入口

答卷数据 → 配额进度。

“问卷信息分享”的公开链接也可查看当前激活版本的配额进度和答卷总览；公开页仅显示进度，不提供导出与配额修改。

## 操作步骤

1. 先看顶部正式／测试和五类结果总览，再查看配额组。
2. 普通组查看总量与检查点明细；交叉组查看组合条件、完成数、备份和状态。
3. 页面可见时每5秒刷新，也可手动刷新。
4. 导出前读取最新一致版本快照，下载包括全部交叉分页的数据。

## 按钮与设置

| 名称          | 位置       | 作用与结果             | 可用条件                 |
| ------------- | ---------- | ---------------------- | ------------------------ |
| 刷新          | 页面工具栏 | 读取最新总览及进度     | 加载／导出中禁用         |
| 导出进度Excel | 工具栏     | 导出普通与交叉统计快照 | 存在激活单元；加载时禁用 |
| 交叉分页      | 交叉表底部 | 切换当前显示单元       | 导出仍包括所有分页       |
| 更新时间      | 工具栏     | 显示本次读取时间       | 并非数据最后作答时间     |
| 正式数／备份  | 配额表格   | 区分目标收取与浮动样本 | 只读，不在本页改目标     |

## 结果与限制

只按组ID和激活版本归类，未激活草稿不参与进度。有限目标求和，完成数逐单元封顶；不限单元和备份不计总百分比，关闭组保留在完成度口径中。一个答卷可能命中多个单元，所以单元完成数相加不一定等于独立答卷数。维护切版期间以页面提示和一致版本为准。
