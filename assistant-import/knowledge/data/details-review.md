# 答卷详情与审核

详情以该答卷对应的问卷快照解释答案，显示只读题目文本、答案和附件；审核是独立标签。

## 使用前提与入口

结果数据表格右侧操作列。

## 操作步骤

1. 点击查看详情，核对编号、类型、原结果、版本与时间。
2. 逐题查看选择项、分项／矩阵、级联路径、对话或附件；只读，不在此修改答案。
3. 对有效存放记录点击审核，再次点击可撤销。
4. 审核后检查标签变化；统计与配额数量不应因审核标签改变。

## 按钮与设置

| 名称           | 位置         | 作用与结果               | 可用条件           |
| -------------- | ------------ | ------------------------ | ------------------ |
| 查看详情       | 表格行右侧   | 读取对应问卷快照与原答案 | 请求中防重复点击   |
| 附件预览／链接 | 详情答案区   | 查看已存附件或图像       | 文件存在并可访问   |
| 审核           | 有效答卷行   | 添加已审核标签           | 五类ACTIVE答卷均可 |
| 撤销审核       | 已审核答卷行 | 移除审核标签             | ACTIVE存放状态     |
| 关闭           | 详情窗口     | 返回结果列表             | 不修改答案         |

## 结果与限制

TRASH与DELETED只能阅读，不能审核或修改类型。没有历史快照时不套用当前题干猜测答案；旧配额满记录未保存答案时明确显示缺少历史内容。审核不把备份变成完成，也不让测试计入正式统计。
