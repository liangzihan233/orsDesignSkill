# 保存、模拟答题与发布

保存是更新设计，发布是建立答题版本。顶栏返回按钮会回到我的问卷；离开前先保存当前编辑。预发布供测试并锁结构，正式发布用于正式收集。

## 使用前提与入口

问卷工作室顶栏。“外观设计”“收集设置”和“答卷数据”的各子页持续显示“测试发布、预发布、正式发布、返回编辑”按钮组。

## 操作步骤

1. 编辑时点击保存，或开启自动保存；一般编辑自动保存每60秒检查脏状态；收集设置使用独立的500毫秒防抖自动保存，不受顶栏自动保存开关控制。
2. 点击测试发布，在新窗口检查完整流程；允许浏览器弹窗。
   新窗口先显示同源加载页，测试凭证准备完成后再进入答题，不再先停留在空白页。
   在设计工作区使用“多题测试”时，可选择多道题并打开临时预览；每次发起测试会清除此前的多题测试缓存，因此旧测试链接刷新后可能失效。预览会包含当前尚未保存的设计内容，不提交答卷。浏览器存储空间不足时会提示清理此站点的其他本地数据。
   选题列表按题目编码和标题识别题目，与设计页一致。系统自动补入能识别的依赖题，并在测试页标出补入题的编码；按原问卷顺序先填写来源答案。来源题未作答时，关联选项可能全部隐藏，目标题也会被跳过。
3. 需要测试答卷时使用预发布，确认后建立预发布快照并进入测试答题。预发布成功后，原“预发布”按钮变为“停止发布”。
4. 内容编辑页点击发布先进入外观设计；在外观设计、收集设置或答卷数据中点击“正式发布”并确认后发布，进入收集链接。正式发布成功后，原“正式发布”按钮变为“停止发布”。
   内容编辑页点击发布后，按钮立即进入加载状态，旋转图标替换原发布图标；保存及页面切换完成后离开内容编辑页。
5. 预发布或正式收集中，在外观设计、收集设置或答卷数据顶栏点击对应的“停止发布”并确认。停止后当前发布快照关闭，已打开的预发布答题页也不能继续提交；返回“问卷设计”即可恢复结构编辑，修改完成后再发布。停止状态的设计页始终读取最新已保存草稿，历史预发布快照不会覆盖题目删除等修改。再次预发布固定修改后的草稿并恢复结构锁；预发布快照不分配正式版本号，正式发布才生成正式版本号。

## 按钮与设置

| 名称     | 位置                 | 作用与结果                           | 可用条件                                 |
| -------- | -------------------- | ------------------------------------ | ---------------------------------------- |
| 保存     | 顶栏                 | 整卷保存到服务器                     | 结构未锁定；处理中不重复操作             |
| 自动保存 | 顶栏开关             | 每60秒保存未保存改动                 | 仅开启且存在改动、非收集中、非锁定时执行 |
| 测试发布 | 按钮组               | 先显示加载页，再以 dryRun 模式预览   | 不写入答卷；需允许弹窗                   |
| 预发布   | 按钮组               | 创建预发布版本，进入可提交的测试流程 | 确认后锁定结构                           |
| 发布     | 编辑／公式／逻辑页面 | 先保存并前往外观设计                 | 此步尚未最终发布                         |
| 正式发布 | 外观／收集／数据顶栏 | 确认后发布正式版本并进入收集链接     | 服务器发布成功                           |
| 停止发布 | 当前发布按钮原位置   | 关闭当前发布快照，允许结构编辑       | 预发布或正式收集中；需要确认             |
| 返回编辑 | 按钮组               | 返回内容编辑页                       | 发布期间仍受结构锁定约束                 |

## 显示条件与计算等待

选择、取消选项或填写补充文本时，只更新本地答案，不执行公式、显隐、自动选择和跳转计算，可以连续多选。互斥选项和最多选几项等输入限制仍即时生效。进入题目、点击下一题／确认／下一页或最终提交时，才按最新答案执行对应生命周期计算与校验；同页其他题目的显隐和关联选项也在这些时点统一更新。正式答题的草稿同步继续独立进行。

连续填写矩阵或快速修改答案时，正在保存的请求继续完成，尚未发送的旧进度合并为最新答案。当前题校验、跳转逻辑和必要的配额检查通过后即可继续，不再等待远程进度保存。进度在后台同步，失败后重试；支持本地存储的浏览器会保留草稿。最终提交直接发送完整答案，不再先等待重复的进度保存；只有服务器确认成功才显示完成并清除草稿，提交失败可重试。

多题测试和外观预览会执行选项、矩阵行列的显示条件。首次计算完成前显示加载状态，不提前展示尚未判定可见性的题目。计算期间暂时锁定答题控件，完成后恢复。仅引用题目数据、使用受支持只读操作的纯表达式，在其依赖未变化时复用成功结果；答案、可见性或表达式定义变化会重新计算。涉及上下文、时间、函数模式或写入行为的脚本仍正常执行，不套用该缓存；真正执行时保持独立沙箱，取消或超时会终止当前执行。服务端会复用相同完整问卷定义的成功编译结果，减少提交校验开销；不会跳过发布指纹和答案校验。

## 结果与限制

正式与预发布都锁定题目、公式、逻辑、呈现模式。外观可走受限保存，配额走独立版本接口。测试答卷不占正式配额；dryRun 模拟不会保存答卷。停止收集后重发属于新发布批次，配额重分配只处理当前激活批次。

预发布遇到校验失败、快照不一致或服务故障时显示实际拒绝原因，保留草稿供处理后重试；只有服务端明确判定凭证无效或过期才显示凭证错误页。

测试发布使用只读模拟凭证，服务端拒绝保存答卷和答题进度。预发布使用独立测试快照与凭证，保存的答卷标记为“预发布答卷”，不占正式配额或正式版本号；正式发布后，它们仍关联原测试快照。无法证明来源的旧测试记录单列为“历史测试”。

编码审核覆盖当前题型面板可见题型，隐藏题型不单独扩展编码模型。点击确认应用后，系统先将审核草稿提交服务器，成功才更新正式问卷；失败保留原内容和审核草稿，按定位提示修正并重新检查、确认。提交期间不能关闭或编辑审核。其他编辑已更新服务器设计时，需要重新加载并重新审核。

编码与内部 ID 分开保存，历史编码占用记录用于防止误分配；服务器会复检确认、残留引用和编码归属。审核窗口打开期间普通保存与自动保存暂停，避免影响正在审核的基线。

## 离开前确认保存

当前仍有自动保存开关与手动保存按钮，普通编辑按 60 秒间隔检查改动；尚未切换为输入停止后立即保存。离开工作室或关闭浏览器前先手动保存并确认成功，失败时保留当前内容并重试。不能把本地缓存当作所有尚未上传改动的断网备份。编码影响审核期间普通保存和自动保存暂停，审核确认成功才应用新编码。

## 多题测试的依赖范围

只选 Q22，而 Q22 的显示代码读取 Q18 时，测试自动加入 Q18；若 Q18 又依赖其他题，会继续补入，循环引用不会重复加题。支持直接题目编码、`context.questions` 字面量、结构化条件和关联来源、富文本答案引用及字面量跳转目标。全局公式与规则仍运行，因此会保守补入其中引用的题目；跨题钩子也可能扩展测试范围。

测试页显示“自动补入 N 道依赖题”和对应编码。补入只影响这次临时测试，不修改问卷设计，不生成来源答案，仍需按实际规则答题。

动态拼接题目编码、共享运行变量或无法解析的代码，不能保证静态识别全部依赖。测试页会提示并提供“改用整卷测试”，切换时重新开始本次测试。整卷测试仍是本地预览，不保存答卷。静态分析也会读取未启用的代码草稿，可能保守多补题或提示；完整流程最终应使用测试发布验证。

提交期间如答案、附件或当前答题会话发生变化，旧请求的返回不会清除新草稿或将当前页面标记为提交成功。请以当前页面最终确认的结果为准。
