# 富文本、图片与答案引用

题目、说明和选项可直接编辑文字，也可打开富文本窗口设置格式或插入图片、已有题目的答案引用。

## 使用前提与入口

点击题干、问卷标题、说明或选项文字，使用富文本编辑入口。

## 操作步骤

1. 直接输入文字完成小幅编辑；需要格式或媒体时打开完整编辑器。
2. 使用工具栏调整文字、段落、链接并上传图片。
3. 在支持引用的位置选择前序题目及其可用答案维度，插入引用节点。
4. 点击确认应用富文本，保存问卷；通过模拟答题检查引用随答案变化。

## 按钮与设置

| 名称       | 位置             | 作用与结果                   | 可用条件                           |
| ---------- | ---------------- | ---------------------------- | ---------------------------------- |
| 富文本编辑 | 文字旁编辑入口   | 打开独立编辑窗口             | 当前字段支持富文本                 |
| 图片上传   | 富文本工具栏     | 上传图片并插入正文           | 上传成功且文件符合限制             |
| 答案引用   | 编辑器工具栏     | 插入受访者前序答案的动态占位 | 仅提供当前位置允许的题目维度       |
| 移除引用   | 引用节点删除控件 | 移除该引用节点               | 支持引用删除的字段                 |
| 确认       | 窗口底部         | 应用本次窗口内容             | 整卷持久化还需保存                 |
| 关闭       | 窗口底部         | 关闭窗口                     | 未确认编辑不会作为本次窗口结果应用 |

## 焦点与保存

仅点击题干再切换页面不会更改文字或产生属性覆盖。直接输入会更新草稿，离开输入区域不会再次写入；保存问卷后可刷新核对。富文本窗口仍以确认按钮应用编辑。

## 结果与限制

更新于 2026-10-25。答案引用嵌入题目或选项的句子时，来源选项的外层段落不会额外拆行；加粗、斜体、文字颜色和图片继续保留。来源内容有多个段落或显式换行时，仅在引用内部保留换行。选择题答案和变量返回的富文本共用此显示规则，不改变原答案、逻辑计算或提交内容。

引用用于展示，不等于逻辑判断或公式变量赋值。被逻辑隐藏的答案会被清除，引用可能变为空。跨题引用复制到独立题库时会被清理并提示。

## 选项禁止引用答案

单选、多选及兼容选择题可在“选项属性 → 选项配置”逐项开启“禁止引用答案”，默认关闭。开启项不出现在对应富文本答案引用中，已有引用也会过滤；全部已选项被排除时展示为空。矩阵以题目答案生成动态行时同样排除这些选项。原题仍可选择、提交，普通逻辑和公式仍读取原答案；变量返回文本不按此开关追溯过滤。详见[选项配置](http://design.ors-cn.com/agent-help/articles/design/properties/options.md#禁止引用答案)。
