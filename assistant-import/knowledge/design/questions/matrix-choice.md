# 矩阵选择题与矩阵填空

矩阵入口将原矩阵单选与多选合并为一个可切换模式的题型。行是评价项目，列是可选答案。

## 使用前提与入口

问卷编辑 → 左侧题型面板。点击题型加入当前选中题之后，或拖到画布指定位置；选中题卡设置右侧属性。结构锁定时先停止收集。

## 操作步骤

1. 添加矩阵选择题，编辑行与列；可逐项添加、拖动排序或按行批量添加。
2. 选择单选或多选模式，设置必答。
3. 在题目属性设置表格／逐行展示和转置；在选项属性的“行选项／列选项”Tab 分别配置当前轴、顺序及逐项显示代码；行分组位于行选项 Tab。
4. 按需配置不可选单元格；单选可设置答案不重复和相似度校验。
5. 需要动态行时添加一个动态行，根据来源答案生成项目，预览检查。

自 2026-10-23 起，新建矩阵的行编码默认 A1、A2，列编码默认 S1、S2；新增行列沿用各自计数器继续分配，不自动回收删除编号；原行列删除后，可通过编码审核手动复用其编号。已有问卷保存的编码（包括旧的行 S1、列 A1 或自定义编码）保持不变，缺少编码的行列按新默认规则补齐。行列编码在“选项属性 → 选项配置”中编辑。先切换“行选项／列选项”Tab，再通过下拉框选择具体行或列，修改编码后离开输入框自动检查；失败恢复原值，通过后明确确认引用影响并应用。也可批量修改当前 Tab 的全部编码，数量须与当前轴现有项一致。重排、转置及单选／多选切换保留编码。

右侧不再展开“行设置”和“列设置”列表。矩阵选择题的行列文字、增删和排序在画布完成；“配置选项”只显示当前选中行或列的编码及适用属性。矩阵填空及兼容题型在对应 Tab 的下拉框选中行或列后编辑标题，选中列还可配置输入类型、提示和下拉选项。

行与列顺序分别保存，可独立选择默认、随机、循环或倒序；公开答题按对应顺序展示，转置后仍保留原行列身份。随机顺序由答题种子稳定生成，循环顺序使用现有答题序号；未设置的历史问卷保持默认顺序。设置只改变呈现，不改行列内部 ID、编码或答案映射。

## 结果与限制

矩阵填空位于矩阵题区域，接口提供模板或未提供模板时均只显示一个入口；可逐格输入文本，每格按稳定的行列身份保存，答案详情和导出按行列展开。数值、下拉、组合、量表和滑块仍被隐藏，不能通过此入口创建。动态行与转置会影响显示，需检查逻辑及公式采用的是答案身份还是位置。

动态行使用计算变量时，系统先完成变量与联动计算，再生成可作答的行。加载或修改配置期间不会把动态行占位名称当作真实行，也不会提前删除已恢复的动态行答案。变量计算失败会显示错误并阻止提交；不会把失败当成空名单。

逐行模式在手机上将进度与前后行按钮分行显示。单元格超出屏幕时可以横向滚动，导航按钮保留在可视区域。

## 矩阵填空的字数限制

在“题目属性 → 填空设置”设置每个文本单元格的最少／最多字数，默认 0／99999。题目级范围优先于已保存的列范围，未设置题目范围时继续使用列限制。数字、日期和选择单元格不套用文本字数。需在测试中逐格检查空值和越界内容，详见[文本输入设置](http://design.ors-cn.com/agent-help/articles/design/properties/options.md#文本输入的填空设置)。

## 取值与可用函数

以下以本题实际编码为 `Q1` 为例，`Q1` 与 `context.questions.Q1` 等价。`Q1` 本身是题目对象，公式应返回具体字段或计算结果。字段支持表中的驼峰写法及大写协议名（如 `value`／`VALUE`、`hasAnswer`／`HAS_ANSWER`）；方法名区分大小写。

| 写法                                  | 含义与返回值                                           |
| ------------------------------------- | ------------------------------------------------------ |
| `Q1.rows`                             | 全部行对象，包含未答行；用行 `VALUE` 正式编码定位。    |
| `Q1.answerRows`                       | 已作答行对象数组。                                     |
| `Q1.cols`                             | 实际列对象数组，排除行标题占位列。                     |
| `Q1.value`／`Q1.values`               | 展平后的答案标识；一项时 value 为单值，多项为数组。    |
| `Q1.answer`／`Q1.answers`／`Q1.label` | 选择矩阵为已选列标题；填空矩阵为单元格输入的文本表示。 |
| `Q1.hasAnswer`                        | 至少一行有答案，不表示全部必答行已完成。               |

通用身份字段：`Q1.id` 为内部 ID，`Q1.code` 为题目编码，`Q1.type` 为内部题型。`Q1.isShow` 仅在运行器提供显隐快照时可读；缺少快照会报错，自动选择条件禁止读取。

未答时 `value`／`answer` 为 `null`，`values`／`answers`／`answerRows` 为空；`rows`／`cols` 仍保留定义。

### 按行列编码直接读取

以下统一假设题目编码为 Q1、行编码为 A1、列编码为 S1。请替换成问卷实际保存的编码；旧问卷如果行叫 S1、列叫 A1，仍按原编码引用，不按字母推断行列。

| 对象                  | 简写       | 明确指定行列         |
| --------------------- | ---------- | -------------------- |
| A1 行                 | `Q1.A1`    | `Q1.$row.A1`         |
| S1 列                 | `Q1.S1`    | `Q1.$col.S1`         |
| A1 行与 S1 列的单元格 | `Q1.A1.S1` | `Q1.$row.A1.$col.S1` |

设计时已保存的静态行列支持上述直接编码对象。动态生成的行继续使用已有 `ROWS` 和答题机制，不提供直接编码属性。

| 读取内容     | 行                | 列                | 单元格               |
| ------------ | ----------------- | ----------------- | -------------------- |
| 值           | `Q1.A1.value`     | `Q1.S1.value`     | `Q1.A1.S1.value`     |
| 答案显示文本 | `Q1.A1.answer`    | `Q1.S1.answer`    | `Q1.A1.S1.answer`    |
| 是否有答案   | `Q1.A1.hasAnswer` | `Q1.S1.hasAnswer` | `Q1.A1.S1.hasAnswer` |

| 题型     | 行 `.value`                   | 列 `.value`                   | 单元格 `.value`              |
| -------- | ----------------------------- | ----------------------------- | ---------------------------- |
| 矩阵单选 | 已选列编码或 `null`           | 已选行编码数组，未答 `[]`     | 选中为 `true`，未选为 `null` |
| 矩阵多选 | 已选列编码数组，未答 `[]`     | 已选行编码数组，未答 `[]`     | 选中为 `true`，未选为 `null` |
| 矩阵填空 | `{列编码: 输入值}`，未答 `{}` | `{行编码: 输入值}`，未答 `{}` | 实际输入值或 `null`          |

`answer` 返回相应显示文本：选择矩阵的单元格为已选列标题或 `null`，行按单选／多选返回列标题或列标题数组，列返回已选行标题数组；填空矩阵的单元格为输入的文本表示，行列按对侧编码汇总文本。`hasAnswer` 是布尔属性；行或列只要至少一个单元格有答案即为 `true`，不表示已满足全部必答要求。这些读取属性只读，获取选中编码数组优先使用下文的 `select()`。

### 简写与显式行列路径

`$row`、`$col` 是平台提供的行列命名空间，不是 JavaScript 的特殊语法。在编码唯一且没有名称冲突时，简写与显式路径指向同一对象，取值、选中判断及写入权限完全一致。

`Q1.$col.S1` 表示整列；`Q1.$row.A1.$col.S1` 表示交点。还可写成 `Q1.A1.$col.S1`：先定位 A1 行，再明确指定 S1 列的单元格。

简写的注意事项是名称冲突：

- 行列都叫 X 时，使用 `Q1.$row.X`、`Q1.$col.X` 区分。新改码审核会阻止跨行列重名；这里兼容历史已保存的同名编码。
- 行编码为 `value` 时，`Q1.value` 是题目的值，应使用 `Q1.$row.value` 访问该行。
- 列编码为 `select` 时，`Q1.A1.select` 是该行的查询方法，应使用 `Q1.A1.$col.select` 或 `Q1.$row.A1.$col.select` 访问单元格。

编码无冲突时可以正常简写；编写通用脚本或需要明确表达行列身份时，可统一使用显式路径。两种写法都按保存的编码绑定实体，重排、随机显示或转置不会改变引用的行列身份。改码审核会对可识别的静态引用同步更新，必要时补上安全命名空间；动态拼接或逃逸引用仍可能需要人工审核。

### 行列与单元格的显隐

在显示逻辑的代码规则中，`hide("Q1.A1")` 隐藏整行，`hide("Q1.S2")` 隐藏整列，`hide("Q1.A1.S2")` 仅隐藏交点；`show(...)` 恢复对应目标。同码时使用 `Q1.$row.A1` 或 `Q1.$col.S2`。同一目标按代码执行顺序以最后一次显隐决定为准；隐藏行、列或交点会清除该位置的旧答案和补充文本。分步显示时，必答行的所有可选交点若都被隐藏，可直接进入下一行。动态行不支持直接编码目标。

### 兼容的行列集合字段

`Q1.rows` 中的行对象字段为 `VALUE`、`TEXT`、`LABEL`、`CELLS`、`ANSWER_VALUES`（已答列编码）、`ANSWER_TEXTS`、`ANSWER_LABELS`、`IS_ANSWERED`、`SCORE`；`Q1.cols` 中的列对象字段为 `VALUE`、`TEXT`、`LABEL`、`SCORE`。这组集合对象与 `Q1.A1`、`Q1.S1` 编码对象的结构不同：集合中的 `VALUE` 是行列编码，编码对象的 `.value` 是答案汇总。`CELLS` 以列编码为键：选择单元格通常为 `true`／`null`，填空单元格为实际输入值／`null`。

选择矩阵的 `values` 如 `["A1:S2"]`；输入矩阵如 `["A1_S1:很好"]`。定位具体答案使用 `rows.find(row => row.VALUE === "A1")?.CELLS.S1`，不要按视觉位置猜身份。题目级 `score` 当前不按矩阵单元格汇总；选择矩阵按行 `SCORE` 读取配置分值，业务汇总可用 `SUM(Q1.rows.map(row => row.SCORE))`。

### 可用方法与写入限制

本题没有普通选择项：`Q1.select()`、`Q1.unSelect()` 返回 `[]`，`Q1.isSelected("A1")`、`Q1.unSelected("A1")` 返回 `false`。这些查询不能代替本题的答案读取。

矩阵单选、多选的**行、列对象**支持下列选择查询。以保存的行编码 A1、列编码 S2 为例，`Q1.A1.select()` 返回该行已选的列编码，`Q1.S2.select()` 返回该列已选的行编码；单选也返回数组，未选返回 `[]`。行列同码时使用 `Q1.$row.A1`、`Q1.$col.S2`。

| 方法                    | 含义                                                                          |
| ----------------------- | ----------------------------------------------------------------------------- |
| `axis.select()`         | 已选编码数组，按设计时对侧行列的顺序排列。                                    |
| `axis.unSelect()`       | 静态对侧行列中未选的编码数组，包含隐藏或禁用但未选的交点，不表示可作答集合。  |
| `axis.isSelected(code)` | 指定交点是否选中。                                                            |
| `axis.isselect(code)`   | `isSelected` 的兼容别名。                                                     |
| `axis.includes(code)`   | 与 `isSelected(code)` 相同。                                                  |
| `axis.unSelected(code)` | 指定交点存在且未选中。不存在的编码返回 `false`。                              |
| `axis.isin(codes)`      | 已选项非空，且全部属于候选编码数组；等价于 `ors.isin(axis.select(), codes)`。 |
| `axis.notin(codes)`     | 已选项全部不属于候选编码数组；等价于 `ors.notin(axis.select(), codes)`。      |

`axis` 代表行或列对象。行方法接收列编码，列方法接收行编码；单编码参数支持字符串和有限数字，按字符串比较。`isin/notin` 必须传编码数组，缺参或类型错误会报错。未答时 `isin` 为 `false`、`notin` 为 `true`；候选数组为空时也分别为 `false/true`，不能代替必答校验。`isSelected/isselect/includes` 对不存在的编码返回 `false`。

例如 `Q1.A1.includes("S2")` 判断 A1 行 S2 列是否选中，`Q1.S2.isin(["A1", "A2"])` 判断 S2 列是否至少有一行选中且选中的行全部在 A1、A2 内。至少命中一个候选项可写 `["S1", "S2"].some(code => Q1.A1.isSelected(code))`；指定候选项全部选中可写 `["S1", "S2"].every(code => Q1.A1.isSelected(code))`。后两种写法沿用原生 JS 的空数组规则，动态参数在改码时可能需要人工审核。

行列使用带参数的方法，单元格直接读取布尔属性：`Q1.A1.isSelected("S1")`、`Q1.S1.includes("A1")` 与 `Q1.A1.S1.isSelected` 判断的是同一交点。单元格的 `isSelected` 不加括号。`Q1.A1.select().length` 是该行选中列数，`Q1.S1.select().length` 是该列选中行数。矩阵填空不提供这些选择查询，通过 `value/answer/hasAnswer` 读取输入。

`select/unSelect` 每次返回独立原生数组，可使用 `.length`、`.includes()`、`.some()`、`.every()`、`.map()` 和 `.filter()`，修改数组不会回写答案。选择数组也支持 `axis.select().isin("A1", "A2")`、`.notin(["A3"])`、`.any("A1")`，包括 map/filter 后的数组。数组链式使用严格类型匹配，支持单值、数组、多参数；矩阵对象本身的 `axis.isin(codes)/axis.notin(codes)` 仍要求数组并按字符串比较。详见[集合函数合同](http://design.ors-cn.com/agent-help/articles/design/conditions/functions.md#数组链式集合判断)。方法名区分大小写；列编码与行方法重名时，用 `Q1.$row.A1.$col.select` 这样的显式路径访问单元格。矩阵填空通过 `value/answer` 读取输入，动态行继续使用已有集合读取。

题目级 `Q1.setValue`、`setSelection`、`selectOption`、`deselectOption` 和 `clear` 仍不可用。仅在 `initializeAnswer`、`resolveNext` 可写钩子中，选择交点可执行 `Q1.A1.S2.setSelected(true)` 或 `setSelected(false)`；填空交点可执行 `Q1.A1.S2.setValue("很好")` 或 `clear()`。写后同一钩子读取 `value`、`answer` 会立即得到新值。单选矩阵每行至多选择一列，多选矩阵保留多列；填空值遵守该列文本长度、数字范围、日期格式或下拉选项设置。隐藏、禁用或已受答题保护的交点不可写；任何写入失败都会放弃本次钩子的全部改动。显示逻辑和计算公式不可写。不能直接给 `Q1.value` 或单元格 `value` 赋值；读取属性返回的数组或对象只读；`select/unSelect` 返回的独立数组可以在脚本中修改，但不会回写答案。

例如，在本矩阵的“答案预填代码”中执行 `Q1.A1.S2.setSelected(true)`，随后读取 `Q1.A1.S2.isSelected` 或调用 `Q1.A1.isSelected("S2")` 都得到 `true`，`Q1.S2.select()` 也立即包含 A1。隐藏交点并清理答案后，选择查询同步反映清理结果。

### 修改单元格答案速查

| 题型与操作           | 简写                          | 显式路径                                |
| -------------------- | ----------------------------- | --------------------------------------- |
| 单选／多选：选中     | `Q1.A1.S1.setSelected(true)`  | `Q1.$row.A1.$col.S1.setSelected(true)`  |
| 单选／多选：取消选中 | `Q1.A1.S1.setSelected(false)` | `Q1.$row.A1.$col.S1.setSelected(false)` |
| 填空：修改输入       | `Q1.A1.S1.setValue("很好")`   | `Q1.$row.A1.$col.S1.setValue("很好")`   |
| 填空：清空输入       | `Q1.A1.S1.clear()`            | `Q1.$row.A1.$col.S1.clear()`            |

以上写法仅在 `initializeAnswer`、`resolveNext` 可写钩子中执行。选择格使用 `setSelected`，填空格使用 `setValue/clear`；行列没有批量 `setValue/setSelection` 接口，需要修改多个交点时逐格调用。不能通过 `Q1.A1.S1.value = ...` 或修改 `select()` 返回的数组回写答案。

### 计算示例

假设矩阵选择题行 A1 为服务、A2 为质量；列 S1 为一般、S2 为满意；仅 A1 选中 S2。在变量素材中选择 JavaScript 函数模式、结果类型“对象”：

```js
function compute(context) {
  const row = Q1.rows.find(item => item.VALUE === "A1");
  return {
    values: Q1.values,
    columns: row?.ANSWER_VALUES ?? [],
    satisfied: row?.CELLS.S2 === true,
    titles: MATRIX_ROW_TITLES(Q1.rows, "S2"),
    answeredRows: Q1.answerRows.length,
    selectedColumns: Q1.A1.select(),
    selectedRows: Q1.S2.select(),
    selected: Q1.A1.isselect("S2"),
    included: Q1.S2.includes("A1"),
    inSet: Q1.A1.isin(["S1", "S2"]),
    outside: Q1.S2.notin(["A2"]),
    sameRowSelection:
      JSON.stringify(Q1.A1.select()) === JSON.stringify(Q1.$row.A1.select()),
    sameCellValue: Q1.A1.S2.value === Q1.$row.A1.$col.S2.value,
    cellSelected: Q1.A1.S2.isSelected
  };
}
```

### 矩阵填空示例

`MATRIX_ROW_TITLES(rows, ...columns)` 只匹配值严格为 `true` 的选择单元格，不用于筛选文本或分数。多选矩阵一行可有多个 `true`；文本、数字、日期和下拉列需读取实际 `CELLS`。

假设矩阵填空题 A1 行 S1 列填“很好”，A2 行尚未填写。在变量素材中选择 JavaScript 函数模式、结果类型“对象”：

```js
function compute(context) {
  const row = Q1.rows.find(item => item.VALUE === "A1");
  return {
    cell: row?.CELLS.S1 ?? null,
    values: Q1.values,
    answeredRows: Q1.answerRows.length,
    rowValue: Q1.A1.value,
    columnValue: Q1.S1.value,
    directCell: Q1.$row.A1.$col.S1.value,
    directAnswer: Q1.A1.S1.answer,
    directHasAnswer: Q1.A1.S1.hasAnswer
  };
}
```

预期：

```json
{
  "cell": "很好",
  "values": ["A1_S1:很好"],
  "answeredRows": 1,
  "rowValue": { "S1": "很好" },
  "columnValue": { "A1": "很好" },
  "directCell": "很好",
  "directAnswer": "很好",
  "directHasAnswer": true
}
```

## 行分组与固定位置

分组使用稳定 ID 保存成员；更改组名或移动分组不会更换行身份。一个行只能属于一个分组；删除分组后保留原行，作为未分组行展示。组间顺序和组内行顺序分别设置，固定分组保留组位置，固定行保留所在排序集合中的位置。隐藏组名只隐藏标题，成员仍可作答。

不可填写单元格可以从配置列表删除；删除后保存会清除该交点的禁用记录，再次设置则使用同一行列身份。

矩阵题卡底部工具栏在可用空间不足时自动换行。添加行、列、动态行、批量操作和可输入选项均保留在中心编辑区内，不与右侧题目操作按钮重叠。

矩阵图形规则的触发选项只列出实际可作答列，不包含左侧行标题占位格。新建规则默认选择第一个实际选项；多选条件命中任意选定列时按现有规则执行显示或跳转。

## 动态行编码

动态行以单选、多选等选择题的答案作为来源时，选项属性中开启“禁止引用答案”的选项会被排除。原题仍正常保存这些答案；全部已选项被排除时不生成动态行。变量来源继续使用变量返回的文本数组，详见[选项配置](http://design.ors-cn.com/agent-help/articles/design/properties/options.md#禁止引用答案)。

静态行使用保存的行编码。运行时从来源题或变量生成的行在创建时分配 `S_D_` 开头的独立编码，编码随稳定身份保留；来源顺序变化、隐藏或重新出现不会重新编号。该前缀属于系统派生行命名空间，不能用于其他静态行。动态行的答卷快照记录内部身份、行编码、标题及来源行身份，便于后续准确解析。

## 行列自己的显示条件

更新于 2026-10-23。打开“选项属性 → 显示逻辑”，在同一窗口分别查看行选项和列选项，每项只有一个单行表达式。只接受同步 boolean 结果，`false` 隐藏该行或该列，`true` 仍须满足其他显隐条件。详见[显示逻辑](http://design.ors-cn.com/agent-help/articles/design/properties/options.md#显示逻辑)。行列配置、列输入类型、附带文本限制、动态行入口、行顺序和分组统一位于选项属性；整题展示、转置、布局和整体约束仍在题目属性。

## 配置弹窗关闭保存

更新于 2026-10-23。“矩阵行分组”关闭时保存已确认的分组、排序和固定设置，未确认的新增／编辑表单会放弃。“设置单元格不可填写”通过“保存并关闭”提交即时修改。两处弹窗的右上角关闭和 Esc 执行同一保存流程。

保存使用整卷保存入口，成功后才关闭；失败时保留当前状态并提示重试。没有待保存修改时不发送保存请求。已有明确保存或确认按钮的其他配置弹窗保持原有操作方式。

`initializeAnswer` 只能修改本题答案，并且一次调用不能同时返回 answer 和调用答案修改方法；`beforeShow` 只返回本题展示文案，禁止写答案。已有恢复或人工答案优先，预填执行资格与一次性状态见[四个题目钩子](http://design.ors-cn.com/agent-help/articles/design/properties/common.md#四个题目钩子)。
