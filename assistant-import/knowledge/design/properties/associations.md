# 题目关联

题目关联把前序单选或多选题的选项用于另一道题。每条关联选择“选中项”或“未选中项”；目标题仍由受访者独立作答。可添加多个来源，同名选项也分别保留来源身份与本题编码。

## 设置关联

1. 在设计页选中单选、多选、多项评分、排序或矩阵题，点击题卡底部最右侧的“关联”。
2. 点击“新增关联”，选择前序单选／多选题，再选“选中项”或“未选中项”。同一位置不能重复选择同一道来源题。
3. 矩阵题分别在“行关联”和“列关联”页签设置。两种关联可同时使用，与动态行设置独立。
4. 点击弹窗中的“保存”，再保存问卷。刷新设计页后仍保留关联设置和项目编码。设计页显示来源的全部可引用选项，关联项旁的“关联自 Q1/A1”标记指明来源题和来源选项编码。关联标题随来源更新；通过弹窗删除关联。

来源选项开启“禁止引用答案”后，不进入任何关联目标。目标项有自己的稳定编码，因此可以独立用于题目逻辑、公式及导出。评分题为每个关联项单独评分；矩阵行和列分别使用关联来源的标题。

## 答题与统计

来源题有效作答后，“选中项”只显示所选来源选项，“未选中项”只显示当时可见、可引用而未选的来源选项。来源未答、被隐藏或跳过时，对应关联项不显示；来源答案变化会清除目标中不再可用的答案。目标没有可作答项时自动跳过，不要求必答。

提交时会再次核对来源题的图形显隐逻辑与显隐条件；隐藏来源题的旧答案不能让关联项重新变为可提交。无效的来源选项或目标关联项身份也会被拒绝，矩阵填空内容仍可自由填写。

Excel 按各答卷的发布版本保留目标题全部可能的关联项列，受访者未看到的项按未选或未作答填写。来源题与目标题分别统计；多项评分、排序和矩阵继续使用本题自己的项目编码。

## 使用限制

- 只可关联排在目标题之前的单选、多选题；来源题可有自己的关联，因此可形成连续关联。
- 同一道来源题在目标的同一维度只能出现一次；矩阵的行、列属于不同维度。
- 已被其他题关联的来源题或来源选项，需先移除关联再删除。发布时会检查来源、顺序及关联项身份。
