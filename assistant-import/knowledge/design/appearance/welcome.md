# 欢迎页、隐私协议与签名

欢迎页在开始答题前展示标题、说明、协议与签名要求。隐私阅读和签名都能阻止未完成前置流程的受访者进入。

## 使用前提与入口

外观设计 → 欢迎页设置。

## 操作步骤

1. 选择是否显示欢迎页及隐私协议；默认显示欢迎和隐私，默认不强制阅读或签名。
2. 修改同意说明与协议链接名称；需要时上传 txt、md 或 PDF 协议。
3. 需要阅读确认时开启强制阅读；受访者打开协议并满足计时后确认。
4. 需要签名时开启签名要求，测试绘制、重签与确认。
5. 保存后用同一问卷公开链接刷新，完整检查入口。

## 按钮与设置

| 名称               | 位置         | 作用与结果                     | 可用条件                     |
| ------------------ | ------------ | ------------------------------ | ---------------------------- |
| 显示欢迎页         | 欢迎页设置   | 控制入口欢迎内容               | 受隐私与签名前置要求约束     |
| 显示隐私协议       | 欢迎页设置   | 显示同意流程                   | 关闭同时清除强制阅读要求     |
| 必须阅读隐私协议   | 隐私子设置   | 使用阅读计时确认流程           | 仅显示协议时可配置           |
| 协议文案／链接名称 | 隐私子设置   | 修改入口同意文字               | 不改变协议文件               |
| 上传协议／清空     | 隐私子设置   | 保存文件信息或恢复默认协议     | txt、md、pdf；上传成功后保存 |
| 必须签名           | 欢迎页设置   | 未签名禁止进入；提交时上传 PNG | 需完成签名确认               |
| 阅读确认           | 答题协议弹窗 | 满足阅读计时后记为已确认       | 阅读要求开启                 |
| 重签／确认         | 答题签名窗口 | 清除重画或确认当前签名         | 有有效签名                   |

## 结果与限制

普通协议模式仍需勾选同意；强制阅读时按阅读确认流程。PDF内嵌预览，文本读取失败回退内置协议。签名保存到答卷公共信息，不等于独立“签名题”的答案；部署的上传与存储可用性须以实际环境为准。

## 长说明与进入按钮

更新于 2026-10-25（系统 1.256）。科技欢迎页的桌面左侧内容可以滚动；说明较长时，向下滚动即可操作隐私同意、签名与进入按钮。短屏和手机仍使用自然页面滚动。此修复不增加外观字段，也不改变已有欢迎、隐私或签名配置。
