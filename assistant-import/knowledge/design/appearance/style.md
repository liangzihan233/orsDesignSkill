# 外观模板与设备样式

外观设计仅提供科技风格模板，并分别预览桌面、平板和手机的图片样式。

## 使用前提与入口

问卷设计 → 外观设计。已发布问卷可保存允许修改的外观，答题呈现模式仍受结构锁限制。

## 操作步骤

1. 左侧仅保留科技风格；历史经典、星空 ID 自动回退科技风格，保留问卷自身配置。
2. 选择一页一题或对话窗口；已发布锁定时该控件禁用。
3. 设置题号、进度、标题、说明、题型名称、编码、预计用时等显示项。
4. 设置颜色和各设备图片，再在预览中检查。
5. 修改后等待外观自动保存完成，刷新公开链接核对实际效果。

## 按钮与设置

| 名称                     | 位置           | 作用与结果                                         | 可用条件                           |
| ------------------------ | -------------- | -------------------------------------------------- | ---------------------------------- |
| 模板卡片                 | 左侧模板列表   | 当前仅提供科技风格                                 | 取消保持原模板                     |
| 设备切换                 | 预览／图片设置 | 切换桌面、平板、手机配置                           | 颜色等公共设置不随设备独立         |
| 答题呈现方式             | 公共样式       | 一页一题／对话窗口                           | 结构锁定时禁用                     |
| 显示项复选框             | 公共样式       | 控制题号、进度、页眉、题型、标题说明、分值和编码等 | 部分编码可指定题目范围             |
| 预计用时                 | 公共样式       | 默认估算或自定义分钟数                             | 开启后显示模式输入                 |
| 主题／背景／Logo／进度色 | 颜色设置       | 更新对应区域颜色                                   | 应用到当前外观                     |
| 页头／背景／Logo图片     | 图片设置       | 启用并上传设备对应图片                             | 文件需通过大小限制                 |
| 清空                     | 图片旁         | 移除该图片配置                                     | 不删除问卷题目                     |
| 页眉页脚                 | 公共样式       | 配置桌面与手机图像                                 | 上传成功后生效                     |
| 自定义 CSS／历史脚本     | 按设备样式     | CSS 可编辑保存；历史脚本只读保留                   | CSS 应用于公开答题；历史脚本不执行 |
| 提交／上一页／下一页文字 | 按钮设置       | 替换答题按钮文字                                   | 空值使用默认文案                   |

一页一题预览在答题中默认显示“下一题”，进入结束确认状态后显示“提交答卷”；按钮设置中的自定义文字优先显示。

## 结果与限制

外观预览不能代替公开链接实测。第一阶段不开放整卷脚本，历史自定义 Script 只读保留，公开页与编辑预览均不执行；题目行为请使用内容编辑中的三个钩子。自定义 CSS 仍按设备保存并应用。历史经典、星空及未知模板 ID 均回退科技模板，下次保存规范化为科技模板。

呈现方式与选项编码显示可以独立调整；设备样式为空时也可保存，之后可继续设置各设备的外观。

## 页面切换与加载

内容编辑和外观设计之间切换时，导航先响应，首次页面加载及预览初始化分别显示加载状态。外观设置面板在同一问卷内保活，返回时按当前问卷同步；离开外观设计时已有待保存修改在后台提交，保存失败仍会提示。隐藏期间释放答题预览，返回后重新启动预览，临时预览答案重新初始化。此过程不改变问卷正式答卷。

## 预览计算与脚本报错

修改外观颜色、显示项或欢迎页样式，以及自动保存回写相同内容时，预览保留当前答案，不重新执行题目渲染钩子。修改题目或逻辑仍会重新初始化预览。

预览在首次显示条件计算完成后再展示题目，等待期间显示加载状态。矩阵所有行都被条件隐藏时，整题暂不显示；选择来源题对应选项后，符合条件的行重新出现。取消来源选项会清除对应隐藏行的答案。

一页一题按生命周期运行答案预填与题目渲染逻辑。脚本运行于隔离沙箱，不能使用浏览器的 `window`、`location` 或 `URLSearchParams`。公开答题链接的业务查询参数通过 `context.system.params` 读取；访问凭证等保留参数不会注入。无参数的本地预览按参数缺省值执行。

例如 Q1 的 A1 为线上、A2 为线下，读取 `code` 后自动完成渠道题：

```js
function initializeAnswer(context) {
  const code = context.system.params.code;
  Q1.selectOption(code ? "A1" : "A2");
  return { mode: "autoComplete" };
}
```

上述代码放在渠道题的“答案预填代码”中，返回 `show` 或 `autoComplete` 模式，且只能修改本题答案。题目是否显示由本题布尔显示表达式负责；渲染钩子只返回 `{view:{...}}` 展示文案。脚本报错时修正错误后重试；系统不会跳过报错并替受访者生成答案。原整页问卷统一按一页一题执行，渲染与跳转钩子也会生效。
