# 交叉配额向导

交叉配额将2至4道选择题放到行列轴，形成按组合控制的配额单元。三步均可保存，但前两步是关闭的未完成草稿。

## 使用前提与入口

配额管理 → 交叉配额 → 新增交叉组。

## 操作步骤

1. 第一步填写名称，选择2至4道不重复且有有效选项的题目；可保存后继续编辑。
2. 第二步在左侧勾选选项，拖到行轴或列轴；每轴可用两级。需要合并多个原始选项时先组合、命名，再放置。
3. 检查结构矩阵预览，确认轴上题目与组合正确，再继续到目标设置。
4. 第三步逐单元填目标；空白表示不限，0表示不接受正式完成。可用批量目标填写多个单元，浮动量必须为正整数。
5. 保存完整组；需要参与答题收取时启用并等待激活完成。

## 按钮与设置

| 名称               | 位置           | 作用与结果                       | 可用条件                   |
| ------------------ | -------------- | -------------------------------- | -------------------------- |
| 添加题目／删除题目 | 第一步         | 维护2至4题维度                   | 不能重复；少于2题不能删除  |
| 下一步             | 向导底部       | 校验当前步骤后继续               | 题目或结构合法             |
| 保存当前步骤       | 第一／二步底部 | 持久化当前草稿并关闭窗口         | 不会提前启用或激活未完成组 |
| 组合选项／取消组合 | 第二步选项栏   | 合并同题原始选项形成一个分类     | 需选中可组合项             |
| 重命名组合         | 组合项         | 修改组合显示名称                 | 不改变组合成员             |
| 拖放／移回／清空轴 | 第二步行列区   | 构建或调整交叉结构               | 满足题目归属与轴层级限制   |
| 批量目标           | 第三步顶部     | 向矩阵单元填入目标               | 目标为非负整数或空白       |
| 浮动量             | 第三步顶部     | 设置交叉单元备份余量             | 正整数，最大1000000        |
| 行／列分页         | 第三步矩阵底部 | 查看大矩阵不同区域               | 只改变显示，不裁掉保存单元 |
| 上一步             | 向导底部       | 回到前一步调整                   | 保存中禁用                 |
| 保存               | 第三步底部     | 保存完整配置；已启用系统按需切版 | 目标与浮动量合法           |

## 结果与限制

修改题目集合会确认清空结构和目标；改变结构组合会确认清空目标；只改名称保留后续数据。相同题目或结构重新保存可保留已完成步骤。未完成组不能启用、没有可导出的完整Excel矩阵。组合数过大时向导会拒绝生成，需减少维度或组合。

## 配额检查点

第三步可为整组选择最多三道检查点题目；它们决定提前检查的时机，和交叉轴的条件依赖分别保存。历史未指定配置按条件推导，最终提交仍检查全部启用配额。空交叉组可保留为禁用草稿，不能启用。
