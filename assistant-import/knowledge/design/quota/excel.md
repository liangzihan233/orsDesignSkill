# 配额 Excel 导入与导出

配额Excel用于交换配额定义，不包含实际答卷；配额进度Excel是另一份统计快照。

## 使用前提与入口

配额管理工具栏“导入／导出Excel”。

## 操作步骤

1. 先导出当前配置作为格式样本，保留普通与交叉两类sheet结构和题目、选项映射。
2. 填写目标，交叉目标空白为不限，0为有效目标；不要把空白自动改成0。
3. 选择文件导入，先核对校验问题、组数与单元数。
4. 全部合法后确认，将导入组追加为关闭的草稿组；逐组检查后再启用。

## 按钮与设置

| 名称      | 位置       | 作用与结果               | 可用条件                       |
| --------- | ---------- | ------------------------ | ------------------------------ |
| 导入Excel | 配额工具栏 | 打开文件校验窗口         | 维护中禁用                     |
| 选择文件  | 导入窗口   | 解析文件并显示问题和摘要 | 支持约定Excel格式              |
| 确认导入  | 窗口底部   | 整体校验通过后追加草稿组 | 有合法组且无校验错误           |
| 取消      | 窗口底部   | 关闭导入窗口             | 不追加组                       |
| 导出Excel | 工具栏     | 下载配额定义             | 配置完整；未完成交叉组明确报错 |
| 导出进度  | 配额进度页 | 下载最新统计快照         | 与配置Excel不同用途            |

## 结果与限制

导入不会自动启用。交叉浮动量不进入Excel，导入默认2；普通目标／浮动量与交叉目标语义不同。不要用Excel导入替代发布版本管理；运行生效仍要启用配额组并等待切版。

## 不限额与独立检查点

普通配额目标空白也表示不限额，0是有效有限目标，浮动量仍须为正整数。普通和交叉配额Excel无法表达与条件依赖不同的独立检查点；此类配置明确拒绝导出，避免导入后改变检查时机。空草稿不具备完整可导出的配置。
