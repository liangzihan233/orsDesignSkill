# AI 配置与共享模型

AI 配置保存服务地址、接口协议和模型标识，供智能建卷与 AI 访谈题选用。模型及默认模型由登录用户共享，只有管理员可以维护。

## 使用前提与入口

侧栏“我的资源 → AI 配置”。普通用户可查看模型；具有管理员角色的账户显示添加、编辑及设为默认操作。题目角色卡的维护权限与模型配置不同。

左侧“我的资源”中的 AI 配置使用齿轮图标；AI 角色卡和题库分别使用机器人和书本图标，“我的数据”使用数据库图标。

## 操作步骤

1. 管理员点击“添加模型”，填写配置名称，选择 OpenAI 兼容或 Anthropic 接口协议。
2. 填写服务商提供的 API 基础地址、准确模型标识和 API Key。快捷填充只填写地址及协议，模型标识和密钥仍需自行填写；Anthropic 地址不需要附加 `/messages`。
3. 选择启用状态并保存，核对列表。保存失败时保留窗口，根据错误修正；保存配置不代表已完成模型连通性或生成质量验证。
4. 对已启用模型点击“设为默认”。建卷工作台和题目模型选择框在尚未选模型时会使用已启用的共享默认模型；没有默认值时手动选择。
5. 修改已保存模型时，密钥留空表示保留原密钥；填写新密钥才替换。完成后用一次实际建卷或访谈请求核对服务是否可用。

## 按钮与设置

| 名称 | 作用与结果 | 可用条件 |
| ---- | ---------- | -------- |
| 添加模型／编辑 | 保存名称、协议、地址、模型标识、密钥及启用状态 | 管理员；新配置必须提供密钥 |
| 常用服务快捷填充 | 填写服务地址并匹配接口协议，可继续修改 | 不会提供模型标识或密钥 |
| 设为默认 | 更新所有用户共享的默认模型 | 管理员；模型已启用且不是当前默认 |
| 已启用／已停用 | 决定模型能否在选择框中选用 | 停用配置仍可在列表中查看 |
| 重试 | 重新读取失败的模型列表 | 网络或服务恢复后使用 |

## 结果与限制

模型列表与答题页面不返回已保存的密钥。普通用户看不到模型写入操作；不能通过拥有问卷权限获得模型管理权限。模型不可用或已停用时应重新选择，公开访谈失败会保留输入并提示重试，不生成模拟回答。

修改共享默认值不等于改写已有问卷所选模型。更改共享模型的地址、密钥或启用状态前应考虑仍使用该配置的问卷，并在修改后检查真实请求。
