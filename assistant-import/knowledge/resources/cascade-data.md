# 级联数据资源

我的数据保存可复用的树形级联资源，支持可视化节点编辑与JSON编辑。内置资源只读。

## 使用前提与入口

“我的数据”路径 /resources/my-data 当前不在常规侧栏显示，可从相关级联配置或该入口访问；题目属性“配置级联数据”使用这些资源。

## 操作步骤

1. 新建级联资源，填写资源名称。
2. 在可视化模式添加根节点，选择节点后添加子节点、同级节点或编辑。
3. 为每个节点填写显示名称和唯一值，检查右侧选择预览。
4. 或切换JSON模式，填写数组结构并点击应用JSON；保存前修复解析错误。
5. 保存资源，再在级联题配置窗口选择该资源。

## 按钮与设置

| 名称             | 位置         | 作用与结果                 | 可用条件                             |
| ---------------- | ------------ | -------------------------- | ------------------------------------ |
| 新建／编辑       | 资源列表     | 进入级联树编辑器           | 内置资源不显示编辑入口               |
| 删除             | 资源列表     | 确认后删除自建资源         | 内置资源不可删除；先检查使用中的题目 |
| 添加根节点       | 可视化工具栏 | 新增顶层分类               | 不限当前选中节点                     |
| 添加子节点／同级 | 可视化工具栏 | 在选中位置扩展树           | 须选中节点                           |
| 编辑／删除节点   | 可视化工具栏 | 修改或删除该节点及其分支   | 须选中节点；删除需确认               |
| 节点名称／值     | 节点窗口     | 分别定义展示文字与存储身份 | 必填，值在资源内唯一                 |
| 应用JSON         | JSON页签     | 解析并同步树与预览         | 有效非空节点数组                     |
| 保存             | 编辑器顶部   | 校验并保存完整资源         | 名称和节点数据合法                   |
| 返回             | 编辑器顶部   | 返回列表                   | 有未保存内容时提示                   |

## 结果与限制

节点value用于答案身份，不建议在已使用的资源中随意改值。资源题可能在答题时加载远程数据；删除资源会影响读取，题内本地快照仅在相应兼容路径回退。JSON使用label、value、children树结构，勿把显示文字当成唯一标识。
