# 创建与基本信息

专业问卷创建空白问卷。问卷编号用于识别项目；标题是在答题页展示给受访者的内容，设计中仍可调整。

## 使用前提与入口

首页或我的问卷点击“创建问卷”；已有问卷使用更多菜单“设置”。

## 操作步骤

1. 选择专业问卷，填写窗口要求的编号、名称，并补充标签或备注。
2. 确认创建，等待成功后自动进入问卷编辑；在文件夹内创建会归属当前文件夹。
3. 需要修改基本信息时返回列表打开设置，确认保存。

## 按钮与设置

| 名称       | 位置     | 作用与结果                                             | 可用条件               |
| ---------- | -------- | ------------------------------------------------------ | ---------------------- |
| 专业问卷   | 创建窗口 | 提交表单并进入新问卷设计                               | 编号、名称符合窗口校验 |
| 从模板创建 | 创建窗口 | 进入模板中心                                           | 模板中心目前是占位页   |
| AI 创建    | 创建窗口 | 打开智能问卷工作台，可输入需求或上传模板并确认生成结果 | 需有可用的共享 AI 模型 |
| 保存／创建 | 窗口底部 | 向服务器保存基本信息                                   | 处理中避免重复点击     |
| 取消       | 窗口底部 | 关闭窗口                                               | 不保存当前输入         |

## 结果与限制

AI 创建会先生成可检查的大纲与题目；严格模板模式保留原模板题目及选项结构，智能改编可根据需求调整。生成预览不代表已经建卷完成。点击使用后须等待完整保存并进入编辑页；创建基本信息或后续设计保存失败时，根据原窗口错误重试，并核对实际内容，不以列表条目单独判断成功。

## AI 创建的具体流程

AI 创建使用独立工作台：选择共享模型、上传 DOCX 或输入需求，核对预览并点击“使用这份问卷”。与专业问卷先填写编号不同，自由生成使用系统生成的 AI 编号；保存后可通过基本信息设置调整。生成窗口中的待确认事项、失败重试和结构检查见[智能问卷工作台](http://design.ors-cn.com/agent-help/articles/workbench/ai-create.md)。

模板中的甄别问卷、概念测试、口味测试和背景信息会识别为独立分组。原题号（如 S2、A1、A1a）用于生成编辑器基本属性中的题目编号；无题号时按分组使用 S、A、B 或 Q 前缀补齐，并避开原文已有编号。题目编号在整卷内唯一，不随显示顺序改变。选项也生成独立编号，原始数字编码仍保留，例如原值 9 对应选项编号 A9；编号与显示位置分开，倒序量表不会被重新编码。

## 模板逐题理解与补充回答

导入文件后，系统先保存原文，再由 AI 理解题目边界、题型、题干、选项、分组和编号。原始解析结果不会直接作为问卷预览。第一阶段按统一 JSON 结构提取并核验，题型说明与程序说明不能当成答案选项；单选题使用独立选项，不显示整题文本填写框。尚未识别完整的题目显示待确认提示。

第一版题目保存后会显示“题目初稿，逻辑待完善”，随后再补充终止、跳转、条件显示等已支持逻辑。题意或评价对象不清楚时先逐题提问，回答后继续；能力尚未支持的要求仅保留说明，不要求用户逐项取消。此时初稿还不是可直接发布的问卷，完成后仍可进入编辑器修改。结构输出不完整时系统会自动尝试修正一次；仍失败则保留原文和输出，供重试处理，不把错误结构伪装成已完成的文本题。

模板 Agent 会读取完整原文和表格，逐题分析测量目的、分组、编号、题型和关联规则。原文有冲突、找不到被引用题目、缺少素材或存在未接通能力时，优先生成可编辑草稿，将未完成内容保留在核对清单中。仍需补充输入的任务可继续回答后恢复分析。

目前自动编译支持选中或未选中指定选项后甄别终止、条件显示后续题、前向跳转、数字范围与严格递增价格校验。终止访问按筛选结束处理，与正常完成区分。原文编码决定引用关系，例如 A80 的 4–5 与 1–3 分支按实际编码判断，不按显示位置判断。

模板生成优先产出可继续编辑的问卷，不要求百分百复现原文流程。循环测试、跨受访者均衡分配、配额、动态计分、自动计时、工作人员确认和外部素材等尚未接通要求会跳过自动配置，并在生成结果中列出原文位置及说明，供生成后人工补充，不再要求逐条回复“取消这条要求”。跳过的是未接通的执行能力，原题、选项及编号仍保留；同一段里已支持的终止、跳转等规则仍单独处理。关键题意、引用或条件不明确时，Agent 仍可发起询问。

甄别校验会区分“选中则终止”和“未提及则终止”，冲突规则需要人工核对。“居住不足两年才终止”等尚未接通的复合条件会列为待人工补充，不能简化成选中即终止。同一段中的跳转、显示条件与价格不等式分别核对；未完成的条件或比较关系会列入清单，进入编辑器后补充。

题目修复保留已识别的原始题号、选项身份、编码、顺序及甄别标记；原文和处理依据一起保留。内容疑问解决且草稿结构核验通过后，才可点击“进入编辑器完善草稿”，不必先声明所有技术性核对事项都已处理。发起新一轮修改后，旧结果不能直接保存。

内容缺失与能力缺口分开处理。例如“您对\_\_\_\_的口感感觉如何”，提示词已明确产品时由 Agent 填写；仍不明确时展示对应题号、题干、原文和具体问题，逐题回答后再生成。答复进度会保存，重新打开可继续。配额、循环等尚未接通能力只简短说明，不要求填写无法生效的参数，也不阻止进入编辑器。

已支持的规则尽量自动配置。例如选择“喜欢”时显示喜欢原因及后续追问，选择“不喜欢”时显示另一组原因题；原文明确的选项终止访问也会转换为执行规则。无法可靠确定条件时继续询问内容含义，不把所有分支都归为能力不支持。

## 编辑器中的草稿核对清单

编辑器顶部显示待核对数量，点击“草稿核对清单”查看说明和原文。点击“定位题目”进入对应题目；没有对应题目的项目仍保留原文和处理说明。修改完成后逐项勾选“已核对并处理”，也可取消勾选重新核对。完成整体检查后可点击“已核对全部项目”，免去逐项点击；原文和说明仍完整保留。保存问卷会同时保存清单状态，刷新后仍可继续处理。

待核对项目不阻止编辑、保存、预发布及测试答题。正式发布前需完成全部清单；未完成时会打开清单，供逐项处理。人工确认表示已经检查并处理要求，不会自动替用户添加逻辑或素材。

## 生成结果如何核验

点击进入编辑器时若保存失败，当前生成结果会保留。服务恢复后点击“重试这一步”即可重新保存，无需重新上传或再次生成。若提示“问卷脚本服务未配置”，需由管理员配置并启动配套服务；仍须完成实际运行校验才能保存成功。

严格模板、智能改编与自由生成统一在后台任务中进行，提交后页面显示排队、模型分析、题目生成、结果校验等实际阶段。一次模型分析尚未返回时，不显示虚构的逐题完成比例。页面断线或关闭不会自动取消后台任务，重新进入相应生成入口后可从最近任务恢复。连接中断时自动重连，并通过定期查询继续获取结果，不再因页面等待两分钟而中断全卷生成。

需要补充信息时，任务保存问题并等待回答。恢复任务后无需重新上传原文件；补充回答会开始新一轮分析，保留之前的对话上下文。确认生成结果前仍需检查题目、规则和待人工补充的能力。

可以取消仍在执行的任务。取消后旧结果不会应用到模板；已经发送给模型服务的请求不一定能立即停止计费。网络恢复时先连接原任务，避免重复提交。智能改编与自由生成会保存大纲和完整结果检查点；失败后点击重试，在需求、模型和来源内容未变化时继续已有阶段。修改需求会开始新一轮分析。

智能改编需要确认方向时，建议大纲随任务保存；恢复后可确认继续，无需重新上传文件。三种模式共用任务通信与恢复机制，仍分别保留严格模板的逐题澄清、改编方向确认和自由生成的规划流程。模型调用和整个任务仍有时间上限，后台任务并非无限等待。

模型输出保存后，服务重启可从结果校验阶段恢复；尚未收到输出的模型调用可能重新执行，因此不保证从输出中间继续。后台有执行时间和恢复次数上限，超过限制会显示失败，保留原始模板。生成任务完成不等于问卷已经创建，只有核对结果并确认保存成功后才会创建问卷。

规划阶段会对照带版本的前端能力清单，区分已经自动配置、前端已有但模板链路尚未接通，以及尚未核验的能力。能力有代码依据，但不会把“界面上有该功能”当作“本次已经实现”。

生成后先检查真实问卷配置中的题量、编号、选项顺序、分组和矩阵维度，再通过前端现有程序编译器。对于已接通的规则，会运行选中与未选中分支、终止/跳转的执行顺序，以及数值上下界和比较样例。核验不通过会显示原因并阻止创建；确认保存前再次核验。

这些检查验证生成配置与逐题规划是否一致，不能证明模型对所有自然语言含义都理解正确。仍应核对原文、测量维度和关键答题路径；复杂循环、配额事务、外部素材及未明确的业务条件不会因此自动变成已支持。

## 复制已有问卷

在我的问卷卡片或列表的“所有操作”菜单选择“复制问卷”，窗口直接显示新问卷信息表单。名称默认追加“\_副本”，编号留空，标签与备注可修改。填写唯一编号后点击“确认复制”，成功后进入新问卷设计。

副本包含原问卷题目、逻辑、条件变量与外观，内部身份及引用重新建立；新问卷为草稿，不继承答卷、发布记录、来源链接或协作授权。复制失败时保留窗口和输入，服务器回滚本次创建，不留下空副本。

问卷编号在系统范围内唯一，回收站中的编号也不可重复使用。问卷移入回收站满 30 天并由系统成功清空后，编号才可重新使用；创建、复制和修改编号均遵循此规则。
