# 智能问卷工作台

智能问卷工作台把需求对话和问卷预览放在同一窗口，可根据 Word 模板生成，也可从需求起草。生成结果先供核对，点击“使用这份问卷”并保存成功后才进入问卷编辑。

## 使用前提与入口

工作台首页或我的问卷 → 创建问卷 → AI 创建。先选择已启用的共享模型；没有默认模型时可手动选择，没有可用模型时联系管理员在“我的资源 → AI 配置”维护。

## 操作步骤

1. 选择“根据上传模板生成”或“AI 自由生成”。上传模板目前只接受 `.docx`，旧版 Word、PDF 等文件需先另存为 DOCX。
2. 模板方式上传文件后选择“严格生成”或“智能改编”，再描述品牌、产品、占位符和调研目标；自由生成直接输入需求。在“受众与设置”补充目标受众，自由生成还可设置期望题量（4–100，默认 10）及是否包含 AI 访谈题（默认开启）。
3. 点击“生成问卷”。需要补充信息时，逐项点选建议或输入回答，再点“继续”；最后一项点“确认并生成”。有定位链接时可跳到对应题对照。
4. 在右侧核对题目、选项、必答、矩阵行列及 AI 追问要求。模板方式可打开“模板与修改明细”对照全文、识别问题及替换内容。
5. 需要修改时在同一对话中说明具体题号和修改要求，点击“更新问卷”；不输入新要求时可重新生成。智能改编遇到主题差异时，先核对建议，再选择“按此方向继续生成”，或补充其他方向。
6. 严格生成须勾选“我已核对题目与选项，确认使用”。结果就绪且输入框没有待发送修改时，点击“使用这份问卷”，等待保存并进入设计页。再通过模拟答题检查逻辑和填写流程。

## 按钮与设置

| 名称 | 作用与结果 | 可用条件 |
| ---- | ---------- | -------- |
| 使用模型（LLM） | 为生成和修改选择共享模型 | 模型已启用；没有默认值时手动选择 |
| 严格生成 | 保留模板题量、顺序、题型及选项结构，只替换明确内容 | 模板结构已完整识别 |
| 智能改编 | 结合模板和目标调整题目内容 | 须核对主题差异及最终结构 |
| AI 自由生成 | 从需求生成大纲，再生成完整题目 | 有需求与可用模型 |
| 查看这道题 | 从待确认事项定位到右侧题目 | 当前事项有关联题目 |
| 模板与修改明细 | 查看原文、识别与修改依据 | 已读取模板 |
| 重试这一步 | 继续失败的生成或保存步骤 | 没有尚未发送的新要求 |
| 使用这份问卷 | 保存为草稿并进入问卷编辑 | 当前结果通过检查，严格模式另需人工确认 |

## 结果与限制

严格生成不会替受访者填写答案。原文题目或选项未完整识别时，先根据定位调整模板再上传；不能跳过阻塞问题只保存一部分。普通说明或警告与结构错误不同，以明细中的实际问题为准。

自由生成和智能改编若返回核验报告，右侧展示摘要及逐题问题。核验失败或仍有未自动修复的错误时不能使用，应补充要求重新生成；只有警告也应人工核对。早期生成界面的分级报告已经整合到当前工作台，不需要寻找独立的旧核验步骤。

修改失败时旧预览可保留供对照，但不能作为最新结果保存；重试成功后再使用。切换模型、模式或受众设置后需重新生成；更换文件或创建方式会清理对应的上下文与结果。对话和未保存预览只存在于当前窗口，关闭后不能当作已保存问卷恢复。

生成题目的连续章节会转成设计页大纲分组；相同章节名被其他章节隔开时仍是不同分组。AI 访谈题使用本次选择的模型。生成、核验提示和内容预览均不等于已发布，保存后仍需核对属性、逻辑、外观并完成发布。
