# 模板中心与应用中心

当前模板中心提供分类导航占位；应用中心展示预设应用卡片。不能把这些卡片当成已安装、已开通或已接入的服务。

## 使用前提与入口

侧栏“模板中心”及“应用中心”。

## 操作步骤

1. 进入全部模板或问卷、满意度、表单、考试、投票、测评分类。
2. 查看应用卡片说明；如需创建可用问卷，返回我的问卷选择专业问卷。
3. 需要答题页视觉模板时进入外观设计，使用科技风格模板。

## 按钮与设置

| 名称       | 位置         | 作用与结果               | 可用条件           |
| ---------- | ------------ | ------------------------ | ------------------ |
| 模板分类   | 模板中心侧栏 | 切换占位页面             | 尚无可复制模板目录 |
| 应用卡片   | 应用中心     | 显示应用示例说明         | 数据来自预设列表   |
| 创建问卷   | 工作台       | 创建真实专业问卷         | 填写必填信息       |
| 欢迎页模板 | 外观设计左侧 | 真正切换公开答题视觉模板 | 确认后保存         |

## 结果与限制

“问卷内容模板中心”和“外观模板”是不同功能；后者已经接入问卷保存和答题渲染。

## 使用自己的 Word 模板

需要复用已有问卷正文时，使用“创建问卷 → AI 创建 → Word 导入”，上传 DOCX 后整卷生成可编辑草稿，检查后保存并进入设计器。这个已接入的入口与侧栏模板中心分别使用，步骤见[智能问卷工作台](http://design.ors-cn.com/agent-help/articles/workbench/ai-create.md)。
