# 代码与使用问题排查

先看用户已有报错、粘贴位置和期望行为。资料不足时只补问：入口、题型与真实编码、相关代码、实际与预期。不要索要登录密码、Token、整库答卷或无关个人信息；示例答案可脱敏。

| 现象 | 首先核对 |
| --- | --- |
| 找不到 Q1/A1 | 实际编码、来源题是否存在、阶段是否允许读取、是否为局部同名变量 |
| 语法通过但没作用 | 保存和启用状态、所在入口、目标题目、渲染模式、目标平台版本 |
| return false 仍继续 | 是否放在布尔校验入口、是否在真正的入口函数内、是否实际触发该阶段 |
| 提示缺少入口函数 | 该编辑器是否仍要求完整函数；不要默认函数体自动包装已经上线 |
| 显示代码报返回类型错误 | 必须 boolean；不返回 0/1、字符串、数组或对象 |
| 0 被判空 | 是否使用 !value；按题型明确检查空值 |
| 没答就筛选 | !isSelected/notin 包含未答；检查是否需要 hasAnswer，流程判断应放校验后的跳转 |
| 渲染逻辑不能 end/goto | 改为跳转逻辑；渲染只返回 view |
| 矩阵判断相反或不存在 | 题型、行列方向、真实编码及 $row/$col 命名空间 |
| 预填覆盖不了已有回答 | 先检查恢复和人工回答优先规则；不要建议强制覆盖 |
| CSS 无效果或影响其他题 | 实际节点 ID、设备、选择器范围、保存状态；不存在自动占位替换 |
| 本地代码有用线上无效 | 文档、前端和运行服务版本；不要声称只刷新浏览器能解决部署不配套 |
| 代码改名后失败 | 是否仍有旧编码、动态引用或改码审核未完成；按正式引用检查修复 |
| 保存失败或收取失败 | 分开看编译诊断、权限、发布版本、配额和网络；不通过改代码绕过收取规则 |

先复现最小例子，再最小修改。区分编译错误、运行时错误、业务条件不符及平台流程问题。展示修复后的命中／不命中／空答案预期；未实际运行时标注契约核对。仅有局部成功不宣称整卷或数据库通过。
