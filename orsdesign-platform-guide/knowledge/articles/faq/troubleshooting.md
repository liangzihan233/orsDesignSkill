# 常见问题排查

先根据现象检查发布状态、权限、保存结果与筛选口径，再核对功能是否已接入。

## 使用前提与入口

适用于工作台、问卷工作室与公开答题。

## 操作步骤

1. 记录问卷编号、发生时间、当前入口和错误提示。
2. 先保存并刷新相关页面，检查是否仍出现；网络错误时不要反复提交破坏原始状态。
3. 使用下表缩小原因，管理员排查时保留失败请求和服务日志。

## 按钮与设置

| 名称                       | 位置               | 作用与结果                                                           | 可用条件                           |
| -------------------------- | ------------------ | -------------------------------------------------------------------- | ---------------------------------- |
| 发布后题目不能改           | 问卷编辑           | 预发布及正式发布锁结构；先停止收集再改                               | 外观与配额有独立更新接口           |
| 自动保存失败               | 收集设置           | 检查权限、参数与服务器错误，保留编辑内容后重试；发布锁定时先停止收集 | 显示“已保存”后刷新核对             |
| 测试按钮无窗口             | 模拟答题           | 允许浏览器弹窗后重试                                                 | 不要手工拼接无凭证测试链接         |
| 公开链接打不开             | 答题入口           | 检查正式发布、来源启用、时间和密码                                   | 复制系统生成链接，不拼问卷编号     |
| 默认项没有选中             | 答题题目           | 检查是否已有草稿或答案曾被逻辑隐藏清空                               | 默认仅首次可见且无草稿初始化       |
| 填完仍不能下一页           | 答题底部           | 检查必答、其他输入、选择数、倒计时和校验                             | 也检查AI轮次是否完成               |
| 答卷总数与结果列表不一致   | 数据页面           | 总数只计有效正式完成；列表可含测试及其他状态                         | 先统一筛选口径                     |
| 备份没有自动补位           | 废弃后配额         | 当前仅释放额，不自动递补；新答卷可填补                               | 规则更新／启停组会按当前批次重分配 |
| 交叉组不能启用或导出       | 配额管理           | 检查是否只保存第一／二步，需完成目标步骤                             | 0与空白在交叉目标中含义不同        |
| Excel比当前页多            | 结果导出           | 导出全部匹配页，属正常                                               | 强制排除回收站和已删除             |
| PersonID／微信／设备号为空 | Excel              | 当前未采集或保留字段                                                 | 不是导出失败，不应补造             |
| 角色卡换电脑不见 | AI角色卡 | 角色卡已由登录用户共享并保存在服务器，检查登录和资源请求 | 问卷中的角色快照独立保留 |
| 界面语言变了但题目没变     | 语言菜单           | 系统文案与问卷内容分别管理                                           | 当前不会自动翻译问卷               |
| 点击按钮只有提示           | 工作台／数据／设置 | 核对功能状态，可能是占位入口                                         | 使用已实现的专题入口               |

## 结果与限制

如果需要反馈，请提供可重现步骤、错误文字与目标问卷入口；涉及个人信息或真实答卷时避免公开分享全部内容。此手册中的静态事实不等于当前部署已经完成最新后端迁移。

## 新功能排查

- AI 无法生成或使用：先选已启用模型；处理对话中的待确认事项和核验错误。严格模板须核对并勾选确认，输入框中有待发送修改时不能直接使用旧预览。见[智能问卷工作台](http://design.ors-cn.com/agent-help/articles/workbench/ai-create.md)。
- 手机号填了仍不能继续：电话预设内置校验，检查国家／地区和号码；明确固话与分机不接受。普通文本题不会只因标题包含“电话”而自动变成电话预设。
- 字数或附件阻止继续：按每空／每格检查字数，原题必答与附件数量分别满足；等待上传完成。题目附件单文件最大 100MB，其他上传未放宽。
- 时间到后不能提交：整卷倒计时超时保存为未完成；失败时重试保存，不会转为正常完成。欢迎页时间也计入总时长。
- 引用答案或矩阵动态行缺少选项：检查来源选项是否开启“禁止引用答案”；原题选择仍可保留，不应因此重复录入答案。
- 改码后输入恢复：失焦检查未通过会恢复原编码，按格式、重复、历史占用或引用错误修正；通过审核并确认后才应用。
- 公开分享链接无法查看：确认使用答卷数据生成的信息链接、问卷未归档。它与协作授权及收集链接不同，见[信息分享](http://design.ors-cn.com/agent-help/articles/data/sharing.md)。
