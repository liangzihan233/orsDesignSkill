# AI角色卡

角色卡保存名称、说明和角色提示词，方便 AI 访谈题复用。角色卡由登录用户共享维护，保存到服务器；选入问卷后，题内保留独立快照。

## 使用前提与入口

侧栏“我的资源 → AI角色卡”。

## 操作步骤

1. 新建角色卡，填写名称与角色提示词，按需补充说明。
2. 点击保存，然后到AI题基本属性选择角色卡。
3. 查看题内角色快照；修改资源后需要重新选择或更新题内配置才能改变快照。
4. 删除卡片前确认，已保存问卷快照不会随之删除。

## 按钮与设置

| 名称       | 位置     | 作用与结果               | 可用条件             |
| ---------- | -------- | ------------------------ | -------------------- |
| 新建角色卡 | 页面右上 | 打开空白窗口             | 不限是否已有卡片     |
| 编辑       | 卡片行   | 打开该卡片的草稿         | 已登录且卡片存在     |
| 保存       | 窗口底部 | 写入服务器中的单张角色卡 | 名称和提示词非空     |
| 取消       | 窗口底部 | 关闭不保存草稿           | 不限                 |
| 删除       | 卡片行   | 确认后从共享资源移除     | 不会清理问卷角色快照 |

## 结果与限制

角色卡不是系统账户角色。共享模型由管理员新增、编辑并设置默认模型；普通登录用户可选择已启用模型，模型密钥不会返回浏览器。公开答题请求失败时保留输入并提示重试，不生成模拟答卷。

## 共享资源与失败排查

登录其他浏览器或设备后会读取同一套服务器角色卡。若未显示，先检查是否登录成功、列表请求是否失败，再重试；不要把浏览器缓存当作唯一副本。删除共享卡片会影响后续选择，请先核对使用范围，已写入问卷的快照仍保留。模型配置及管理员权限见[AI 配置与共享模型](http://design.ors-cn.com/agent-help/articles/resources/ai-models.md)。
