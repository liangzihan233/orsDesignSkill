# 题库管理与复用

题库用于复用题目文本、题型和普通配置，保存独立内容快照，可从设计页复制入卷。题库题目与问卷中的副本各自编辑，不自动同步。

## 使用前提与入口

侧栏“我的资源 → 我的题库”；问卷编辑左侧“题库”可直接复用。

## 操作步骤

1. 新建题库，填写名称、标签与备注；打开题库查看题目。
2. 新增题目，在单题编辑器选择题型，维护题干、选项与属性。
3. 保存前检查代码与依赖清理提示，确认只保留题目内容和普通属性。
4. 回到问卷设计的题库面板，选择题库并添加目标题目。
5. 已有问卷题也可使用题卡“加入题库”复制保存。

## 按钮与设置

| 名称               | 位置             | 作用与结果                   | 可用条件                                             |
| ------------------ | ---------------- | ---------------------------- | ---------------------------------------------------- |
| 搜索／刷新／分页   | 题库列表         | 查询服务器题库               | 实际接口返回                                         |
| 新建题库／编辑信息 | 列表工具栏或行   | 保存名称、标签和备注         | 名称必填且不超100字；最多10标签，每个20字；备注200字 |
| 预览               | 题库行           | 查看题库内容预览             | 题库有可读取题目                                     |
| 添加题目           | 题库行或题目列表 | 进入单题编辑器               | 有题库编辑权限                                       |
| 切换题型           | 单题编辑器左侧   | 确认后重建当前题目类型       | 原题配置可能被替换                                   |
| 测试本题           | 单题编辑器顶部   | 打开单题预览                 | 题目已加载                                           |
| 保存               | 单题编辑器顶部   | 保存独立题目快照             | 跨题依赖被清理时需确认                               |
| 编辑／删除题目     | 题目列表行       | 修改或确认删除独立题目       | 不自动修改已复制到问卷的副本                         |
| 删除题库           | 列表更多菜单     | 确认后删除题库               | 核对关联题目                                         |
| Excel／文本导入    | 列表更多菜单     | 当前不可用并有提示           | 不支持真实批量导入                                   |
| 加入当前问卷       | 设计左侧题库     | 复制题目并生成适合本卷的身份 | 目标问卷可编辑                                       |

## 结果与限制

加入题库、题库保存、加入当前问卷和题卡“复制本题”都使用同一内容快照规则。副本保留标题、说明、选项及矩阵行列文本、题型、必答等普通配置，并生成新的内部身份；清除自动勾选、题目钩子与自定义 CSS、题目及选项／矩阵行列的显示代码、图形与代码逻辑（含历史显示规则）、计算变量、关联、动态来源、旧代码及其程序元数据。富文本答案引用转为显示文本。

历史题库中的题目加入问卷时也会执行清理，原题库记录与源问卷题目不被改写。复用后如需逻辑或代码，请在当前问卷重新配置。离开有改动的单题编辑页会提示未保存内容。收集设置的随机抽题尚未接入，与此手工复制不同。

“测试本题”使用单独的预览快照，保留本题钩子、自定义 CSS、自动勾选、显示代码和题目规则。预览仍沿用原有单题依赖处理：移除历史跨题逻辑、题内计算变量及旧顶层逻辑／公式字段，将富文本答案引用转为显示文本；此操作不修改源题，也不使用题库保存时的代码清理规则。
