# 文件夹、标签与目录管理

文件夹是问卷的容器，用于目录层级；标签用于筛选。两者分别管理，不会因为勾选标签而移动问卷。

## 使用前提与入口

我的问卷工具栏新建文件夹；文件夹更多菜单改名或删除；标签管理入口维护个人标签库。

## 操作步骤

1. 在当前目录新建文件夹并输入名称。
2. 点击文件夹名称、文件夹图标或更多菜单的“打开”进入目录；在目录内新建的问卷和子文件夹保存到当前目录。通过文件夹菜单改名，从面包屑返回上级。
3. 在问卷设置中选择或输入标签，在工具栏选择标签过滤列表。
4. 删除文件夹前核对内容；非空目录会再次要求确认级联删除。

## 按钮与设置

| 名称         | 位置           | 作用与结果                         | 可用条件               |
| ------------ | -------------- | ---------------------------------- | ---------------------- |
| 新建文件夹   | 工具栏         | 在当前目录新增子文件夹             | 名称通过校验           |
| 打开／重命名 | 文件夹更多菜单 | 进入目录或修改目录名称             | 选中文件夹             |
| 删除文件夹   | 文件夹更多菜单 | 提交目录删除；非空目录提示关联影响 | 确认后调用真实删除接口 |
| 标签管理     | 工具栏         | 查看并选择删除用户标签             | 选中至少一个标签       |
| 删除选中标签 | 标签窗口       | 更新标签库与列表筛选               | 二次确认               |

## 结果与限制

文件夹只提供打开、重命名和移入回收站操作，不显示问卷的设计、收集、数据、分享或预览按钮，也不能生成公开答题链接。刷新列表后仍保持目录类型和层级。

移入回收站会同时处理目录内的子文件夹和问卷；回收站恢复按单个条目执行。恢复时如果原目录已经移入回收站或被清理，条目回到根目录。

修复需要配套后端目录迁移。修复前误建为普通问卷的条目不自动推断为文件夹；请重新创建文件夹，避免误改已有问卷数据。
