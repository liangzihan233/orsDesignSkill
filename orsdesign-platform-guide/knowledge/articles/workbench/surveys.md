# 问卷管理

“我的问卷”按文件夹组织问卷，支持搜索、状态与标签筛选、卡片和列表视图。

## 使用前提与入口

侧栏“工作台 → 我的问卷”。点击文件夹名称进入目录，点击面包屑返回上层。

## 操作步骤

1. 在当前目录创建问卷或文件夹。
2. 输入关键词，配合状态、标签筛选定位问卷；切换视图不会修改问卷。
3. 从问卷卡片或行的更多菜单选择设计、收集、数据、分享或设置。

## 按钮与设置

| 名称                   | 位置           | 作用与结果                   | 可用条件               |
| ---------------------- | -------------- | ---------------------------- | ---------------------- |
| 搜索                   | 工具栏         | 过滤当前目录中的问卷         | 切换目录会清空关键词   |
| 状态筛选／标签筛选     | 工具栏         | 缩小当前列表范围             | 切换筛选回到第一页     |
| 卡片／列表             | 工具栏         | 改变显示方式                 | 不改变保存内容         |
| 刷新                   | 工具栏         | 重新读取列表、标签与配额摘要 | 接口成功才更新         |
| 问卷设计               | 卡片及更多菜单 | 进入问卷编辑                 | 有访问权限             |
| 问卷收集               | 更多菜单       | 进入收集链接                 | 发布状态决定链接可答性 |
| 答卷数据               | 更多菜单       | 进入结果数据                 | 有数据访问权限         |
| 设置                   | 更多菜单       | 编辑编号、名称、标签、备注   | 保存成功后更新列表     |
| 复制问卷 | 问卷更多菜单 | 填写新编号后创建独立草稿副本 | 不复制答卷、发布及授权 |
| 删除 | 问卷更多菜单 | 确认后移入问卷回收站并停止公开访问 | 保留期内可恢复为草稿 |
| 外观／预览 | 问卷更多菜单 | 目前只显示稍后支持提示 | 从设计工作室进入实际外观与测试 |

列表视图的“进度”列仅显示完成数、目标数和百分比，不显示进度条；点击数据可打开配额进度。文件夹显示“—”。页面顶部仅保留文件夹面包屑。

## 结果与限制

列表不会用初始演示问卷代替真实数据。搜索作用于当前目录，不能当成全目录检索。更多菜单的“外观”“预览”尚未接通，实际外观与测试请从设计工作室进入。
