# 工作台首页

首页提供创建入口、近期问卷项目与最近编辑问卷，均读取当前账号有权限访问的真实问卷。

## 使用前提与入口

登录后默认进入“首页”。

## 操作步骤

1. 点击“创建问卷”开始建卷。
2. 点击“我的问卷”查看完整目录。
3. 点击最近编辑卡片进入该问卷设计；配额摘要随可见问卷定期更新。
4. 在“近期问卷项目”查看最近打开或使用的 3 个问卷，点击任意一行直接进入对应问卷编辑。

## 近期问卷项目

进入问卷工作室并成功读取问卷信息后，系统记录该问卷的最近使用时间；内容编辑、外观、收集和数据页面共用记录。重复打开同一问卷会更新顺序，不会重复占用位置。返回首页、切回首页标签或刷新后，按使用时间从近到远显示最多 3 个问卷，并展示真实名称、状态、正式答卷数及最近使用时间。

只有仍在当前权限列表中的问卷会显示，文件夹、已删除或失去权限的问卷不占位置。使用记录不足 3 个时，按最近更新时间补入真实问卷；接口未提供更新时间时使用本浏览器最近保存时间或创建时间。问卷总数不足 3 个时只显示实际数量，空列表显示空状态，加载失败可重试。

使用记录按账号保存在当前浏览器，刷新后保留；更换浏览器或清理浏览器存储后，需要重新积累使用记录，不跨设备同步。

## 按钮与设置

| 名称         | 位置                 | 作用与结果       | 可用条件     |
| ------------ | -------------------- | ---------------- | ------------ |
| 创建问卷     | 欢迎区域             | 打开建卷窗口     | 已登录       |
| 管理全部     | 近期问卷项目标题右侧 | 打开我的问卷     | 不限         |
| 近期项目行   | 页面下部             | 打开对应问卷设计 | 具备问卷权限 |
| 最近编辑卡片 | 欢迎区域右侧         | 打开问卷设计     | 具备问卷权限 |

## 结果与限制

卡片上的正式答卷数与配额百分比采用正式口径，不能据此判断测试、备份和未完成答卷总量。完整总览在答卷数据的配额进度页。
