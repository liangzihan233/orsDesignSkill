# 公开只读问卷信息分享

“问卷信息分享”生成无需登录的只读链接，用于查看一份问卷的配额进度、结果数据、原始列表和答卷详情。获得链接的人可以读取其中的数据；分享前核对问卷内容及接收范围。

## 使用前提与入口

问卷工作室 → 答卷数据 → 顶栏“问卷信息分享”。创建或获取链接需要该问卷的管理权限。

## 操作步骤

1. 点击“问卷信息分享”，确认复制成功；浏览器须允许剪贴板访问。
2. 浏览器无法自动复制时，在弹出的对话框中选择并手动复制完整链接。
3. 用复制的链接打开只读页，默认进入结果数据；顶部可切换配额进度及原始数据。
4. 按类型、结果、版本、审核、存放状态、答案或时间筛选，结合分页查看记录，点击详情读取该答卷答案。
5. 使用刷新按钮读取最新数据；页面可见时每 5 秒自动更新，转到后台暂停，返回时立即刷新。

## 按钮与设置

| 名称                         | 作用与结果                                                                 | 可用条件                           |
| ---------------------------- | -------------------------------------------------------------------------- | ---------------------------------- |
| 问卷信息分享                 | 创建并复制链接；无法自动复制时展示完整链接供手动复制，再次点击获取同一链接 | 问卷存在、未归档且有管理权限       |
| 配额进度／结果数据／原始数据 | 在同一问卷内切换只读页面                                                   | 链接有效                           |
| 筛选／重置／分页             | 查询当前条件的记录                                                         | 仅影响当前页面，不保存为账户筛选   |
| 详情                         | 查看当前问卷某条答卷的完整答案                                             | 记录存在；不能用此链接读取其他问卷 |

## 结果与限制

只读页不提供审核、删除、下载或导出。它与登录工作台的协作分享不同，不授予设计、管理权限；也与收集链接不同，不能用来填写问卷。

公开原始列表使用与结果数据一致的答卷查询，支持测试、未完成等状态筛选；登录工作室的传统“原始数据”仍采用正式完成口径及 CSV 导出，不应将两者混用。问卷归档后链接不可访问；当前页面未提供独立撤销或轮换分享链接的操作。
