# Excel 导出

结果数据提供01与非01两种Excel。导出覆盖当前筛选的全部匹配页，并强制只包含有效存放ACTIVE记录。

## 使用前提与入口

结果数据表格顶部“导出01编码Excel”“导出非01编码Excel”。

## 操作步骤

1. 先在结果页启用需要的类型、结果、版本、审核、答案与时间条件。
2. 选择01或非01编码；等待文件下载，期间按钮禁用。
3. 打开data表查看固定字段和题目列，打开attachment表查看附件链接，打开“题目编码”表核对题干、选项与矩阵行列。
4. 多版本数据按各答卷发布快照解释；缺少的题目列留空。

## 按钮与设置

| 名称              | 位置       | 作用与结果                     | 可用条件                               |
| ----------------- | ---------- | ------------------------------ | -------------------------------------- |
| 导出01编码Excel   | 表格工具栏 | 多选各项选中写1、未选写0       | 未作答整题仍留空                       |
| 导出非01编码Excel | 表格工具栏 | 多选选中写该项编码、未选留空   | 选项列位置与01相同                     |
| 导出按钮禁用态    | 表格工具栏 | 避免重复请求或无效存放导出     | 加载／下载中；仅选回收站或已删除时禁用 |
| data工作表        | 下载文件   | 两行表头：题号分组及完整变量名 | 固定字段后接题目字段                   |
| attachment工作表  | 下载文件   | 每份答卷一行，rid及附件链接    | 有多个附件时向后追加链接               |

## 结果与限制

导出忽略页码，不只当前30条；测试、未完成、备份、筛选和配额满只要ACTIVE且符合筛选均可导出。rid为永久答卷编号，sid为答卷UUID；审核未审0、已审2；结果未完成0、完成1、被筛选2、配额满3、备份9；正式1、测试0。日期使用北京时间原生Excel日期，时长中文显示。前导零或超过15位文本保留为文本，内容不作为Excel公式执行。微信身份、访员、GPS、物理设备号等未采集字段留空；IP／UA只能输出实际可用信息。预发布没有正式版本号时，version 留空。跨版本同名变量必要时附加版本后缀，历史无快照不猜测。附件旧记录仅有URL时原文件名为空，但链接仍导出。

题目列名、矩阵行列和非01选中值使用持久化的正式编码；排序不改变编码。缺失或重复编码会阻止导出并返回校验错误。01多选仍是0/1，分数与排名继续保留原数值。动态行使用答卷记录的行身份与编码，相同身份出现冲突编码时拒绝生成文件。

题目关联的全部可能选项、评分项、排序项及矩阵行列都来自该答卷的发布快照，不按该受访者实际看到的项删列。来源题与目标题分别统计；同名但来源不同的项目使用本题不同编码。参见[题目关联](http://design.ors-cn.com/agent-help/articles/design/properties/associations.md)。

## 城市题地区分类

城市题的 `题目编码__1__open` 列输出所选末级地区编码，例如杭州市为文本 `3301`，不拼接省市路径，前导零保留。相邻的 `题目编码__area` 列输出数字分类：华东一线城市0、华东新一线城市1、华南一线城市2、华南新一线城市3、华中新一线城市4、其他5。01和非01编码采用相同规则；同一问卷的多道城市题分别导出。

内置“中国省市”和“中国省市区”的市级节点包含 `area`，区县继承所属市的分类。选择停在市级时即可取到分类，选择到区县时读取区县节点的同一分类。省级节点没有 `area`，未列入指定城市的市、区县为“其他”。完整分类表见[级联题的城市地区分类](http://design.ors-cn.com/agent-help/articles/design/questions/cascade.md#城市地区分类-area)。

分类依据每份答卷自己的发布快照及已保存的地区路径读取；仅有资源引用的快照沿用现有资源加载流程。未作答、路径无法匹配、资源不可读取或节点缺少 `area` 时，分类单元格留空，不默认写5。编码0正常保留。兼容旧城市题的 `CASCADE/CITY` 格式；自定义级联节点带有 `area` 时也会导出此列，非标准分类保留原文；普通无分类级联保持路径列。答题脚本中的 `.area` 仍为分类文本。

## 历史快照兼容

更新于 2026-10-25（系统 1.261）。同时导出旧预发布和正式答卷时，按各自的原始快照解释答案。旧渲染代码等脚本不符合新版答题合同，不会单独阻止只读导出，也不会在导出时执行或自动改写。

题目、选项、矩阵行列编号仍须完整、唯一并符合命名规则；真实编号或身份冲突会明确报错，不按位置猜测或静默跳过记录。问卷保存、发布和公开作答的脚本权限保持原验证。

## 题目编码工作表

更新于 2026-10-27。01、非01两种导出均在 `data`、`attachment`、`automation` 后追加“题目编码”工作表。表内只有“编号、内容”两列，不含题目流水序号；每题先列正式题号和题干，下方分块列选项，每题之间空一行。编号以文本保存，保留前导零，不随题目或选项排序重新编号。

| 题型 | 内容 |
| --- | --- |
| 单选、多选、下拉、分组选择 | 选项编码与文字；分组选项归在对应组下 |
| 单项输入、多行文本、日期时间 | 题号与题干；没有固定选项，不填入答案、默认值或占位提示 |
| 多项填空 | 各输入项编码与标签；没有标签的内容单元格留空 |
| 矩阵 | 分“行选项”“列选项”；行专属选项另归到对应行，左上角占位格不导出 |
| 排序、评分、量表、滑块 | 排序或评分项目；分值范围、步长和已配置的端点说明 |
| 图片选择、轮播、图片热点 | 文字和图片链接；多张图片分行，链接保留存储地址 |
| 级联、城市 | 节点编码与完整层级路径；城市另列地区分类码说明 |
| 上传、签名、定位、颜色、AI等无固定选项题 | 题号与题干；受访者答案不进入此表，附件链接仍见attachment表 |

富文本转为可读文字，保留换行与图片地址，不执行题目脚本或动态答案引用。描述、分页、分隔线等展示组件沿用原有导出排除规则。内容自动换行；超过Excel行数或单元格文本限制时明确报错，不静默截断。

此表**只包含本次筛选匹配答卷中的最新版本**，不等同于当前设计或最新发布版本。按发布／预发布时间选取；没有该时间的历史快照按匹配答卷的最新创建时间排序，并标明“历史快照”。同时间依次按版本号和稳定ID确定；预发布不虚构正式版本号。

表顶部显示版本标识及“旧版本题目可能未收录”提示。`data` 仍保留本次全部匹配版本的字段与答案；需要核对旧版题目时，先筛选对应版本再导出。没有匹配答卷时，此表保留表头并显示“无匹配版本”，不会使用当前设计补造内容。

## 自动化来源工作表

`automation` 工作表按答卷输出 rid、sid、isAutomation（0/1）、automationRunId及automationSource（BROWSER/SEED）。结果页自动化筛选同时约束导出，原有data和attachment列顺序不变。
