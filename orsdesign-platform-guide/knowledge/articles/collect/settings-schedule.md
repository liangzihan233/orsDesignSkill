# 答题时间安排

时间安排可设置开放日期、每日时段、每题等待倒计时和整卷作答时限；开放日期与每日时段采用北京时间。

## 使用前提与入口

收集设置 → 答题时间安排。

## 操作步骤

1. 选择开始时间和结束时间，清空某一侧即关闭该侧限制。
2. 需要按日开放时开启每日时段，编辑默认09:00至18:00。
3. 点击添加时段补充其他区间，删除不需要的时段。
4. 开启“全局倒计时”并设置秒数，每道可回答题展示后等待相应时间才能回答。题目基本属性中的倒计时优先；明确设为 0 秒表示该题不等待，未设置则继承全局值。描述等展示组件不计时。通过“不应用全局倒计时的题目”下拉，可按题目编码或标题搜索并多选排除题目；所选题目不继承全局等待，题目自身设置的倒计时仍然有效。
5. 开启“全问卷倒计时”并设置总秒数，从介绍页点击“开始答题”进入第一题时开始计时，不包含欢迎页和介绍页停留时间。公开页显示剩余时间；同一浏览器刷新后沿用原截止时间。
6. 设置会自动保存。刷新确认数值后发布相应配置，在公开链接验证等待、总时限及超时结果。

## 按钮与设置

| 名称           | 位置         | 作用与结果             | 可用条件                       |
| -------------- | ------------ | ---------------------- | ------------------------------ |
| 开始／结束时间 | 时间安排     | 保存日期时间与启用状态 | 有效日期；开始不晚于结束       |
| 全局倒计时 | 时间安排 | 为各题提供默认等待秒数 | 开关独立控制，秒数为正整数 |
| 不应用全局倒计时的题目 | 全局倒计时下方 | 多选排除题目，仅免除全局等待；清空选择恢复所有题目继承 | 全局倒计时开启时可设置，支持编码／标题搜索 |
| 全问卷倒计时 | 时间安排 | 限制整卷时长，超时自动结束为未完成 | 开关独立控制，秒数为正整数 |
| 每日时段开关   | 时间安排     | 启用每日时间窗口       | 开启无记录时初始化默认时段     |
| 添加时段       | 时段列表下方 | 追加09:00至18:00区间   | 可继续编辑                     |
| 删除           | 时段行       | 删除当前区间           | 删除最后一项会关闭每日限制     |
| 起止时刻       | 时段行       | 设置每天开放区间       | 开始晚于结束时按跨午夜区间处理 |

## 结果与限制

总日期范围与每日窗口同时满足才能作答；边界包含在允许区间内。错误的时间配置会拒绝访问。测试预览的准入另有测试凭证，不应拿测试入口判断正式开放时间。

开启全局倒计时时，同页各题同时开始各自的等待，较短的题目可先回答，全部等待结束后才能继续；一页一题和对话模式在展示当前题时计时。未开启全局倒计时的历史问卷仍保留同页题目秒数累加后才能继续的规则。

整卷超时会立即停止作答及正常提交，不等待必答或校验通过，保留已答内容并通过进度接口保存为“未完成”，不计为正常完成。完全未作答也会保存未完成记录。保存失败会提示重试并保留本地草稿，刷新后仍为超时。正式与测试答题草稿隔离；已在时限内发出最终提交请求并成功完成的答卷不再超时。清除浏览器数据、更换浏览器或设备不属于原草稿恢复范围。
