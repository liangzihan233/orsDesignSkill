# 收集设置与生效范围

收集设置按九个区域组织。部分字段已有实际访问控制，部分仅提供保存界面；配置已保存不应被理解为后台工作已经完成。

## 使用前提与入口

问卷收集 → 收集设置。修改后自动保存当前问卷配置，无须点击保存按钮。预发布或收集中，不能保存的设置保持禁用。

## 操作步骤

1. 依次检查时间、附件、抽题、安全、体验、追踪、提交、对接和高级设置。
2. 修改后等待页面显示“已保存”；失败时保留编辑内容，点击“重试”。刷新页面核对回显。
3. 顶栏持续显示“测试发布、预发布、正式发布、返回编辑”。预发布后原“预发布”变为“停止发布”，正式发布后原“正式发布”变为“停止发布”；点击并确认后再修改结构或收集配置。原独立“停止收集”按钮已移除。
4. 对已接入的功能，用实际公开链接验证；对仅配置项不要依赖其控制正式数据。

## 按钮与设置

| 名称               | 位置         | 作用与结果                            | 可用条件                     |
| ------------------ | ------------ | ------------------------------------- | ---------------------------- |
| 自动保存状态／重试 | 内容区上方   | 修改后等待500毫秒自动保存；失败可重试 | 草稿或已停止收集，问卷已加载 |
| 开关               | 各设置行右侧 | 修改后自动保存                        | 发布锁定时禁用               |
| 子设置             | 启用开关下方 | 配置时间、数量、网址等参数            | 仅相应开关开启后显示         |

发布前与站内离开页面时都会等待未完成保存；保存失败会留在当前页。发布处理中暂时不能修改设置，避免新改动落在已锁定的发布之后。自动保存不新增收集期修改权限，答卷数量上限继续在配额管理中通过专用接口修改。

## 结果与限制

已接入主链路包括开始／结束时间、每日时段、访问密码检查、返回页范围与受隐私约束的跳过欢迎。附件总控、动态抽题、验证码、BI和多项高级选项存在仅配置能力。设备/IP旧链路有兼容实现，当前新收取链不能统一承诺完整频率策略。详见各篇。
