# 主题、语言与账户菜单

系统主题控制工作台界面，问卷外观控制受访者答题页。语言切换更换系统文案，不翻译题目内容。

## 使用前提与入口

工作台顶部主题图标、语言菜单与头像菜单；工作室顶栏也提供相关账户操作。

## 操作步骤

1. 打开主题设计器，选择浅色／深色／跟随系统及主色方案，检查界面实时变化。
2. 在语言菜单选择简体中文或English。
3. 打开头像菜单查看账户入口；admin可进入账户管理。
4. 退出登录时确认已保存问卷编辑。

## 按钮与设置

| 名称                 | 位置               | 作用与结果                                   | 可用条件                     |
| -------------------- | ------------------ | -------------------------------------------- | ---------------------------- |
| 主题设计器           | 顶部主题图标       | 打开主题面板                                 | 实时应用当前偏好             |
| 浅色／深色／跟随系统 | 主题面板           | 切换工作台颜色模式，跟随系统读取系统明暗偏好 | 不改变问卷所选模板           |
| 预设色／自定义主色   | 主题面板           | 更换系统强调色                               | 自定义色需有效十六进制格式   |
| 重置                 | 主题面板底部       | 恢复浅色与默认蓝色                           | 实时应用                     |
| 保存／关闭           | 主题面板底部或右上 | 关闭面板                                     | 更改已实时应用，不是取消回退 |
| 中文／English        | 顶部语言菜单       | 更换系统界面语言                             | 问卷题干保持原文字           |
| 账户资料             | 头像菜单           | 当前点击仅关闭菜单                           | 尚无完整自助资料管理         |
| 账户管理             | admin头像菜单      | 进入用户管理                                 | 用户名admin可用              |
| 退出登录             | 头像菜单           | 结束当前会话并回到登录                       | 未保存设计应先保存           |

## 结果与限制

浏览器主题偏好与问卷外观不是同一份数据。收集设置的语言种类字段也不等于界面语言菜单；不要期待选择法文后自动生成法文问卷。
