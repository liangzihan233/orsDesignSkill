# 账户与管理员管理

账户管理用于创建系统用户、修改资料、角色和密码，以及启停账户。当前前端入口只对用户名admin开放，不能把ADMIN角色名称等同于页面准入。

## 使用前提与入口

使用admin账户登录 → 顶部用户菜单 → 账户管理；其他用户名访问会跳转无权限页面。

## 操作步骤

1. 新建账户，填写用户名、昵称、邮箱、角色和初始密码。
2. 保存后检查列表中的角色与启用状态。
3. 编辑账户时修改昵称、邮箱、角色；需要重置密码才填写新密码。
4. 对非admin账户使用禁用或启用按钮。

## 按钮与设置

| 名称       | 位置     | 作用与结果             | 可用条件                  |
| ---------- | -------- | ---------------------- | ------------------------- |
| 新建账户   | 页面右上 | 提交新用户资料         | admin入口，服务端校验输入 |
| 编辑       | 账户行   | 修改资料与可更改角色   | 编辑中用户名禁用          |
| 新密码     | 编辑窗口 | 有值时更新密码         | 留空保持原密码            |
| 角色       | 账户窗口 | USER／ADMIN            | admin账号角色选择禁用     |
| 禁用／启用 | 账户行   | 切换账户状态           | admin行没有该按钮         |
| 保存       | 窗口底部 | 调用账户创建或更新接口 | 处理中显示加载态          |
| 取消       | 窗口底部 | 丢弃草稿               | 不修改账户                |

## 结果与限制

账户角色与问卷分享分别控制；创建账户不会自动将所有问卷共享。当前没有完整普通用户自助资料或修改密码页面，管理员可通过此处重置非空密码。
