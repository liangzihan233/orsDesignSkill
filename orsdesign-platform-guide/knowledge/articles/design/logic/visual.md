# 图形演示与题目条件

## 当前实际生效的配置

内容编辑中题卡的“逻辑”配置、题目和选项属性、四个题目钩子，以及条件设置中的计算变量，是第一阶段的实际编辑来源。请在这些入口保存，再在设计预览与公开答题验证条件成立和不成立两条路径。

显示、跳转和校验的图形条件组中，“且／或”显示在相邻两条条件之间，位于前一条表达式右侧；最后一条没有连接符。它表示后一条与前一条的关系。混用时按页面顺序从上到下组合；如需先组合某几条条件，请使用嵌套条件组。旧问卷未逐条设置的条件继续沿用原条件组的“且／或”关系。

条件行统一保留“且／或”的列位置，最后一条不显示连接符时，题目、比较符与比较值仍与上方对应字段对齐。窄屏下连接符与删除按钮排在表达式下方。

在题目逻辑的“跳转逻辑”或“校验逻辑”中点击“添加规则”，首条条件默认选择“题目”和当前题目，判断默认是“已回答”。条件组内点击“添加条件”，以及新增子组、嵌套子组时，也沿用当前题目和“已回答”，仍可更换题目、选项或判断方式。显示条件不指定动作目标；新增跳转规则的“则”默认选择“结束答题”（筛选结束），可改为跳转并指定目标题目，或选择其他结束类型。已有规则不会因新增条件或规则而改变。

显示逻辑使用本题及各子项自身的布尔表达式或自定义代码，两种模式二选一。图形化编辑只生成代码，不保存另一份执行规则；不反显旧代码，覆盖非空内容需确认。可读全卷答案及纯变量，不开放系统来源和副作用。旧显隐配置明确报错，可确认清除；不会继续兼容跨题控制。

跳转与校验逻辑中的条件规则可通过“收起规则／展开规则”折叠条件与执行动作。点击“条件规则 1”等规则标题可输入自定义名称；名称随规则保存，折叠状态只在当前编辑弹窗中保留，不改变规则执行结果。

点击“添加代码”或“编辑代码”后，输入只保留在本次代码弹窗中。点击右下角“保存”通过代码检查后，会直接执行题目逻辑的完整保存校验；成功后保存当前逻辑列表并关闭题目逻辑弹窗，无须再点“保存逻辑”。完整校验失败时保留编辑内容，修正后可再次保存。点击“关闭”、右上角叉号或按 Esc 会直接放弃本次输入：新增代码不会留下代码块，已有代码保留编辑前的内容；即使代码有语法错误也能取消。分组的批量显示代码入口沿用相同行为。

工作区题卡的“题目逻辑”按钮右上角显示红色数量角标，合计当前题目已保存的显示、跳转与校验图形规则及显隐／跳转代码卡片。每张条件规则或代码卡片计一条，停用但保留的卡片也计入，嵌套条件不重复计数。新增、删除规则并保存后更新数字；取消编辑不改变数量，没有规则时隐藏角标。已有问卷兼容统计旧普通题规则、矩阵规则及下一题代码；仅查看数量不会迁移或修改规则。

## 简单表达式与自定义显示代码

更新于 2026-10-27。每行右侧提供“图形化编辑”和“自定义代码”，适用于题目、选项和矩阵行列；分组批量设置使用同一入口。

普通选择题的选中、未选中、包含／不包含、已回答条件直接生成可编辑表达式，例如 `Q1.isSelected("A1")`、`!Q1.isSelected("A1")`、`Q1.hasAnswer`。多条件使用 `&&`、`||` 和括号，保留条件组的从上到下组合顺序。涉及矩阵、正则、比较计算或变量的条件组，以及含 `001` 这类需保留完整数字编码的选项判断，会整体生成代码并打开编辑器；取消编辑器保留原配置。

题目自定义代码声明 `questionVisibility(context)`，选项、矩阵行列声明 `optionVisibility(context)`，两者都必须同步返回布尔值：

```js
function questionVisibility(context) {
  return Q1.isSelected("A1");
}
```

```js
function optionVisibility(context) {
  return Q1.hasAnswer;
}
```

`true` 表示允许显示，其他隐藏原因仍然生效；`false` 表示隐藏。不能返回字符串 `"true"`、`"false"`、数字、数组或空值。缺失正常返回路径及可以确定的非布尔返回值会阻止保存；依赖答案的实际结果由运行器再次严格检查。仅可读取答案和纯变量，不能写答案、联网或使用随机数、当前时间。

自定义代码模式下，输入框只显示“已配置自定义代码”，点击右侧按钮编辑源码。“改用表达式”确认后会清空自定义代码，恢复表达式输入。编辑器保存仅写入外层草稿，还需保存外层显示逻辑；取消外层弹窗不应用草稿。已有表达式及旧生成代码不会自动转换。Excel 多行粘贴范围若含自定义代码，会整批拒绝；请先在对应编辑器确认“改用表达式”。

## 矩阵行列选项树

更新于 2026-10-23。显示、跳转、校验共用的条件来源、比较对象，以及显示目标和逻辑引擎图形演示的目标树，展开矩阵题后分为“行选项”和“列选项”。继续展开分组后选择具体行或列；分组本身不可选择。行显示实际行编码与标题，列显示实际选项编码与标题；矩阵左上角的行标题单元格不作为列选项。只有行的矩阵量表／滑块不会生成虚构的列选项。

选择行时，选中状态表示该行已有答案；选择列时，沿用该列在矩阵答案中被选中或填写的判定。比较对象选择具体行或列时，比较该实体的选中状态；直接选择题目时继续读取整题答案。显示目标可定位具体行或列。保存沿用原实体 ID，调整显示分组不会重建行列、重新编号或改变已有列引用。普通题仍直接展开选项。

## 校验逻辑与重试筛选

在题目逻辑面板中，“校验逻辑”位于“跳转逻辑”右侧。点击“添加规则”，用条件组设置**校验不通过的条件**，再填写重试次数和红字提示语。点击“保存逻辑”应用到设计草稿，并保存问卷。

重试次数表示允许出现提示的次数。每次点击下一题、自动完成或提交而实际进入校验阶段，按当前答案判断一次；答案没有变化也会计数。

| 重试次数 | 条件一直成立时的结果             |
| -------- | -------------------------------- |
| 0        | 第一次校验立即结束，标记为被筛选 |
| 1        | 第一次显示红字，第二次校验结束   |
| 2        | 前两次显示红字，第三次校验结束   |

修改答案、页面重绘和最终提交的网络重试不额外计数。各规则独立记录次数，规则条件不再成立时清零；同一问卷版本的答题草稿刷新恢复次数，重新答题清零。规则按列表顺序判断，第一条阻止或结束的规则生效。选择“仅提示，允许持续修改”时，条件成立只显示提示，不按次数筛选。

图形校验在必答等系统校验之前判断，因此可以配置“未回答”作为筛选条件。图形规则全部通过后，再执行系统校验和原有自定义答案校验。未通过时保留答案，在该题显示红字；达到筛选次数后保留已答内容，以 `SCREENED_OUT` 提交，不要求后续未答题通过必填。它复用结束、进度保存和提交流程，**不再执行下一题图形规则或 `resolveNext` 代码**。一页一题、聊天、合页及整页均使用相同次数规则；整页在提交时进入校验。

“自定义校验代码”打开与基本属性“答案校验逻辑”相同的编辑器，共享同一份代码。代码仍须返回 `true` 或 `false`，可以用 `context.setError("提示内容")` 显示错误。代码返回 `false` 只阻止继续，不自动套用图形规则的重试次数；需要按次数结束时，请配置图形规则。自定义代码保存与图形规则保存分别作用于各自配置。

## 包含与正则条件

更新于 2026-10-24。“包含／不包含”后仅选择两个及以上选项时，显示选项之间的“且／或”；未选或只选一个时隐藏。从多个减少为一个再增加选项，会保留原先选择的关系。

显示、跳转、校验共用条件控件。来源选“题目”时，“已回答／未回答”后提供“包含／不包含”，右侧可多选该题的可选项，下拉项及已选标签显示“选项编码 · 选项文字”，支持按编码或文字搜索。保存后刷新会保留多选，已有单选配置按单个已选项回显。选项旁的“且／或”控制所选项之间的关系，默认“或”：包含时任一项选中即成立，不包含时任一项未选中即成立；选择“且”则分别要求全部选中、全部未选中。这一关系独立于条件行与行之间的“且／或”。按选项身份判断是否选中，而非比较选项文字。没有可选项的题目不能选择这两个判断。切换来源题会清除原选项，复制题目会映射题内引用；删除来源题会移除引用它的整条图形规则，避免删除单个条件后扩大筛选范围。

“匹配正则”使用文本输入框，适用于题目、选项、系统变量和计算变量来源。例如 `^001$` 精确匹配文本 001，`^[0-9]{6}$` 匹配六位数字。直接填写表达式，不加首尾 `/`；正则语法无效时无法保存。原始文本不会先转换成数字，前导零保留。

题目来源匹配实际答案值，数组或复合答案任一值匹配即成立；选项来源优先匹配该项的文本、分数或矩阵单元格值，普通单／多选题的选项匹配选中状态 `true`／`false`。未回答及缺失的文本单元格不匹配，正则不匹配选项的显示标题。原有等于、不等于、大于、小于保持原行为。

## 代码逻辑简写

更新于 2026-10-23。在题目逻辑面板选择对应页签，点击“添加代码”，直接输入操作即可，无须声明入口函数。

| 操作       | 写法         | 允许位置         |
| ---------- | ------------ | ---------------- |
| 跳转题目   | `goto("Q3")` | 跳转／下一题逻辑 |
| 被筛选结束 | `end()`      | 跳转／下一题逻辑 |
| 正常完成   | `complete()` | 跳转／下一题逻辑 |
| 配额满结束 | `full()`     | 跳转／下一题逻辑 |

显示条件例如在 Q3 自身输入 `!Q1.isSelected("A1")`，仅决定 Q3。不能调用 show/hide。跳转仍可写 `if (Q1.isSelected("A1")) goto("Q3");`，命中去向后退出当前代码，无明确去向时继续后续规则。目标支持字符串或动态拼接，运行时检查存在性；静态引用参与改码审核，动态引用不能自动改写。

下一题完整函数保留原返回合同，打开和保存时不自动转换。使用简写请省略入口函数包装；完整函数继续返回跳转指令。完整限制及引用维护见[逻辑操作简写](http://design.ors-cn.com/agent-help/articles/design/logic/dsl.md#逻辑操作简写)，可复制的示例见[逻辑实例](http://design.ors-cn.com/agent-help/articles/design/logic/examples.md)。

## 逻辑引擎的图形演示（2026-10-15）

问卷设计 → 逻辑引擎 → “图形演示”。页面局部规则支持新增、删除、条件分组、动作和预设操作，但所有操作均为演示，不保存、不影响答题或右侧实际程序预览。旧图形数据可作为演示初始内容，修改仅存在于页面内存中，刷新或离开页面即丢弃。

| 入口                       | 当前行为                                         |
| -------------------------- | ------------------------------------------------ |
| 新增／删除规则             | 编辑本页演示副本                                 |
| 条件／条件组、动作、预设   | 试用控件，不生成实际运行效果                     |
| 实际程序／图形演示         | 切换查看方式，不互相生成或覆盖代码               |
| 下载程序                   | 下载真实内容配置及变量生成的程序，与演示修改无关 |
| 保存全局逻辑／编辑整卷代码 | 本阶段不开放                                     |

程序编译出错时须回到诊断指向的原配置入口修复；页面不提供旧程序下载作为兜底。右侧预览始终运行实际内容配置，不能用演示动作验证答题逻辑。
