# 结束页、筛选结束与跳转

结束页面随答题结果显示成功、筛选结束或配额满提示。不同结果决定答卷统计与配额占用，不能只看页面是否结束。

## 使用前提与入口

公开答题的终态页面；结束页文案与跳转配置由已有问卷结束页配置读取。

## 操作步骤

1. 测试普通提交成功的结束页面。
2. 在题目“跳转逻辑”中选择“结束答题”，核对结果数据显示被筛选；选择“成功完成”时走配额检查，选择“配额满”时不占用配额。
3. 测试配额满路径，确认已有答案保留而不计正式完成。
4. 存在结束页跳转链接时，核对链接合法与公开页显示结果。

## 按钮与设置

| 名称               | 位置               | 作用与结果                       | 可用条件                                       |
| ------------------ | ------------------ | -------------------------------- | ---------------------------------------------- |
| 提交               | 答题页底部         | 校验后提交；服务器分配完成或备份 | 必答及校验满足                                 |
| 跳转逻辑的结束答题 | 题目逻辑动作       | 保存已有答案并结束为被筛选       | 条件命中                                       |
| 跳转逻辑的成功完成 | 题目逻辑动作       | 保存已有答案，继续检查真实配额   | 条件命中                                       |
| 跳转逻辑的配额满   | 题目逻辑动作       | 保存已有答案为配额满，不占用配额 | 条件命中                                       |
| 访问链接           | 结束页             | 点击前往配置的外部网址           | HTTP／HTTPS合法地址；预览不执行                |
| 再次答题           | 成功结束页         | 重置本机答题流程                 | 仅允许重复答题时显示；筛选／配额满不显示       |
| 查看我的回答       | 成功结束页次级操作 | 显示本次有效题目与答案文本       | 本次会话有答案时显示；不提供原始数据结构       |
| 提交后自动跳转配置 | 收集设置           | 保存收集字段                     | 与公开页读取的结束页跳转字段并非同一完整配置链 |

## 结果与限制

同一答题尝试的重试沿用原答卷身份，终态写入后，迟到的进度保存不会改写结果。当前外观页面重点提供公共样式与欢迎设置，不能据此认为有完整独立的结束页可视化编辑器。“收集设置”中的提交后跳转等开关须按其实现状态说明使用。
