# 自动选择选项

单选与多选可以按条件自动选择答案，适合用前序答案生成辅助判断。

## 使用前提与入口

选中单选或多选 → 选项属性 → 自动勾选。

## 操作步骤

1. 为需要自动选中的选项填写条件表达式；空条件不参与。
2. 参考变量与函数提示，用当前问卷题目编码编写判断。
3. 按需勾选“直接通过”与“排他”，保存窗口并保存整卷。
4. 在模拟答题修改前序答案，核对自动选项与受访者手动选择的结果。

窗口保存成功后会提示“自动勾选代码保存成功”，并在“自动勾选”按钮右上角显示红色数字，表示当前题目有多少个选项已保存非空且语法有效的自动勾选代码。每个选项只计一次；空代码、无效代码及已删除选项不计入，没有代码时不显示角标。未保存的编辑和取消操作不改变数字，清空代码并保存后数字随之减少。窗口保存将规则写入当前问卷草稿；持久化仍使用整卷手动保存或自动保存，重新加载后按已保存规则恢复数量。

## 按钮与设置

| 名称       | 位置       | 作用与结果                       | 可用条件                     |
| ---------- | ---------- | -------------------------------- | ---------------------------- |
| 条件编辑器 | 每个选项行 | 设置该选项自动命中的条件         | 表达式必须合法               |
| 直接通过   | 窗口底部   | 命中规则后按自动选择流程通过该题 | 具体还受题型与页面导航限制   |
| 排他       | 窗口底部   | 自动命中时排除非命中项           | 用于明确的自动分类           |
| 保存       | 窗口底部   | 写入本题自动选择规则             | 存在表达式诊断错误时拒绝保存 |
| 取消       | 窗口底部   | 丢弃窗口草稿                     | 不改变原规则                 |

## 结果与限制

自动选择使用 JavaScript 表达式或 shouldSelect(context) 函数，严格返回 boolean。只允许前置题答案及其纯公式，前后端共用运行器重算。不能读取后题、运行 vars、网络、当前时间或随机值；后端执行服务不可用时明确失败，不接受未经重算的自动答案。

```js
function shouldSelect(context) {
  const ageValue = Number(age.value);
  return Number.isFinite(ageValue) && ageValue >= 18 && ageValue <= 35;
}
```

直接通过的命中题走完整自动完成生命周期，不占受访者看到的题号；与初始化代码返回 `autoComplete` 的题目一致，后续显示题目连续编号。其答案仍校验、保存并计入配额。排他禁用非命中项；单选多命中报错，不随意选第一项。未命中时保留手工作答能力；联动导致原自动命中失效时清除原自动答案。

多选题未开启“排他”和“直接通过”时，自动命中项与允许的手动选项合并。条件失效只清除先前由自动规则选中的项，保留其余手动选择；开启“排他”或“直接通过”后，命中时只保留自动选项。选项被移除时同时清理其附加文本，仍保留的选项附加文本不变。草稿保存自动选项来源，刷新恢复后继续按相同规则清理；重置答题会清空该来源。

复制题目时，自动选择规则绑定复制后对应的选项，代码原文和禁用状态保留。代码中对其他题目的明确引用继续指向原题目。

## 编辑器提示与验证

自动勾选提示使用 `Q1.value` 和 `Q1.select()`。`ors` 仅用于 `ors.isin`、`ors.notin`，不能写成 `ors.questions.Q1`。表达式和函数脚本都严格返回布尔值。勾选“自动勾选后进入下一题”仍需经过系统和题目校验；“其他未勾中选项不可操作”会锁定未命中的选项。


## 数组链式集合判断

自动勾选支持 `Q1.select().isin("A1", "A2")`（非空且全命中）、`Q1.select().notin(["A3"])`（全不命中）和 `Q1.select().any("A1", "A2")`（至少命中一项）。空答案依次返回 false、true、false，均不能替代必答校验；缺参均返回 false。函数模式同样可在 `shouldSelect` 内返回这些表达式。

链式方法按严格类型匹配，`[1].isin("1")` 为 false。保留的直接 `isin`、`ors.isin` 和矩阵对象方法继续按字符串比较；完整参数边界见[集合函数合同](http://design.ors-cn.com/agent-help/articles/design/conditions/functions.md#数组链式集合判断)。数组方法对所有脚本数组生效，但不允许脚本修改原型，也不会回写题目答案。只能引用本题之前的题目。
