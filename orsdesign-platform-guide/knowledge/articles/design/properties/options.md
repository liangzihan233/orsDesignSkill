# 选项排列、默认值、绑定与分组

选项顺序决定呈现先后，排列决定空间布局。默认项、固定项和绑定分别处理初始答案、随机时的位置及选项协同行为。

## 使用前提与入口

选中有选项的题 → 选项属性。不同题型只显示支持的设置。

## 操作步骤

1. 在最前面的“选项配置”中选择具体选项，修改编码、默认选中、固定和禁止引用答案；修改编码后失焦自动检查。
2. 选择默认、随机、循环或反转顺序。
3. 设置纵向、横向、按列或按行排列，按需分别调整桌面和手机数量。
4. 需要分组时打开选项分组，配置组名、成员、组间顺序、排列及组内顺序。
5. 需要绑定时打开绑定窗口选取关联项；至少两个选项才可建立。

## 稳定编码

更新于 2026-10-25。普通选项在创建时分配并保存 A1、A2 等编码；矩阵静态行默认 A1、A2，矩阵列默认 S1、S2，非矩阵分组或子题仍使用 S1、S2。已有保存编码不会自动交换，新增及缺少编码的矩阵行列使用新前缀。移动、随机排序、删除其他选项及保存回读不会改变已有编码；新增选项使用继续递增的编码，不回收已删除的默认编号。内部 ID 仍负责答案关联，分数和排序题的名次保持原含义。编辑和改名均使用下述编码审核入口。

选项与矩阵行列也支持纯数字编码，例如 `2`、`20`、`98`；按字符串保存，不会按选项位置重编号。脚本使用 `SQ14.isSelected("20")`，矩阵使用明确的轴访问，例如 `D1.$row["2"].isSelected("5")`。矩阵数字行号与列号在各自轴内唯一，可以同为 `2`；有重复时必须使用 `$row["2"]` 或 `$col["2"]` 区分。字母快捷编码仍不允许新建跨轴重名。题目编码仍须以英文或下划线开头；小数、负数、数字开头的混合文字编码不合法。编码冲突、历史归属及改名审核规则继续适用。

## 互斥选项

多选题在“选项属性 → 选项配置”选择某项后，可将“互斥选项”设为“是”。人工勾选该项会取消本题其他选择；再勾选普通项会取消互斥项。适用于“以上皆无”等答案，沿用选项稳定 ID，保存刷新后保留。自动勾选、预填与恢复答案仍遵循各自合同，不通过本次点击规则改写。

## 禁止引用答案

在“配置选项”中选定一个选项，将“禁止引用答案”设为“是”并保存。每项独立设置，默认“否”，保存刷新后保留。富文本的“引用答案”引用整题答案时会过滤开启的选项；矩阵单选、矩阵多选以该题作为动态行来源时，也不会为这些选项生成行。已有引用同样按当前设置过滤。全部已选项都被过滤时，公开答题中引用内容和对应动态行为空；关闭后恢复正常引用。

原题仍可选择并提交这些选项，默认选中、必答、选项顺序、条件、配额、逻辑和公式读取原答案的规则保持不变。兼容的图片选择、分组选择和下拉选择沿用此设置；下拉选项的附加输入也会从直接引用菜单和已有选项引用中排除。计算变量返回的文本不带来源选项身份，变量引用和变量来源动态行继续使用变量返回值。

## 结果与限制

刷新继续答题时已有草稿优先于默认项。逻辑隐藏题或选项会清除答案，重新显示也不会恢复被清除的默认值。“继承父级”选择框当前没有完整可选规则，不应当成已配置继承。

## 修改选项与矩阵行列编码

选中题目，在右侧“选项”页签最前面的“选项配置”中，通过“配置选项”下拉框选定具体项，再修改下方的选项编码。只展示当前项的输入框，选项再多也不会展开全部编码。矩阵行列及子题使用相同的下拉选定编辑方式；矩阵题在“选项属性 → 选项配置”中先切换“行选项／列选项”Tab，再选择当前轴的具体项，占位角不参与编码。

修改完成后离开编码输入框，系统自动检查整份问卷的引用影响，无须再点击“检查编码变更”。格式、重复、历史占用或引用检查不通过时，输入框立即恢复原编码并提示原因。检查通过才进入引用影响审核；正式问卷保持原值，直至确认并应用。取消审核保留原问卷。

编码变化并检查通过就会打开审核框，即使自动同步引用为 0 处也一样；代码入口列出全卷代码，默认显示的题目不代表存在编码冲突。服务器保存失败时，审核框会持续显示具体返回原因；例如“问卷脚本服务不可用”表示保存服务链路异常，不表示新编码已被占用。

“批量修改选项编码”打开时预填全部现有编码，按选项顺序一一对应；矩阵只预填当前行／列 Tab 的编码，数量按当前轴检查。可用中英文逗号、空格或换行分隔，编码数量必须与现有项数一致。离开输入框自动检查，失败整批恢复原值，通过后统一确认引用影响。此入口只修改编码，保留选项文字、内部身份、排序、默认与固定设置；不会新增或删除选项。需要追加选项时使用工作区的批量添加。

选项编码还需避免与题目属性或方法名称（例如 `VALUE`、`select`）冲突，也不能与其他选项的 `OPTION_编码` 引用产生歧义；此类变更会被审核阻止，需要取消后选择其他编码。

普通选项改码或删除后，原编码仍归原实体，不能转给其他实体。矩阵行列改码后，只要原行列仍存在，原编码也保留占用；原行列删除后，可以通过编码审核手动将其编码用于新行列。原实体可改回自己的编码。复制题目或整卷时，会为复制后的内部身份重建归属映射。

## 文本输入的填空设置

填空、多行填空、多项填空、横线式多项填空及历史问答题，在“选项属性 → 填空设置”配置“最少多少字”和“最多多少字”，默认分别为 0 和 99999。没有选项列表的非矩阵文本题也会显示“选项属性”页签。矩阵文本输入统一在“题目属性 → 填空设置”配置。单行、多行填空的输入类型同时移到该区块。

多项填空的范围分别作用于每个空；矩阵题分别作用于每个文本单元格，数字、选择和日期单元格不使用字数限制。矩阵未设置题目字数范围时沿用已保存的列限制，设置后以题目范围为准。已有问卷明确保存的限制保持原值。

最少值超过最多值时同步提高最多值；最多值低于最少值时同步降低最少值。最少值可设 0，最多值可设 1–99999。留空是否允许由“是否必答”决定；非空内容须符合范围，才可继续或提交。答案引用、条件设置与公式继续读取原有文本或分项答案结构。

## 可输入选项的字数限制

在“选项属性 → 选项配置”的“配置选项”下拉框中选择可输入选项，会额外显示“字数限制”，可分别设置“最少多少字”和“最多多少字”，默认 0／99999。普通选项不显示此属性。每个可输入选项独立保存，修改时保留原占位说明、多行输入和是否必填；最少、最多值交叉时另一端同步调整。

限制针对该选项的附带文本，不是整道题或所有选项的合计。答题时仅校验已选且可见的输入项；可选输入允许留空，填写后须满足字数范围；必填输入仍须填写。取消选择或逻辑隐藏沿用原有清理规则，不会因残留文本阻止继续／提交。单选、多选、下拉及兼容的可输入选项共用此设置。

矩阵选择题在“选项属性 → 选项配置”的“配置选项”中选中可输入列后也可设置，每行该列的附带文本分别校验。已有问卷明确保存的字数范围继续保留。答案引用、变量和导出仍按原有附带文本结构读取。

## 矩阵行列编码范围

更新于 2026-10-23。同一道矩阵题手动或批量修改行列编码时，新编码不能与另一行或列重名，大小写不同也算重复。例如第一列已经是 A1，新行就不能再改为 A1；不同题目的 A1 互不占用。新增或补齐编码也会跳过本题另一轴正在使用的编码，已有编码不会因此自动变化。

历史已保存的行列同名仍可用 `$row`／`$col` 显式引用；系统不自动迁移它们。再次改码时应选择本题尚未使用的编码。矩阵行列的原项删除后，可手动复用其编码（例如删除旧行 S1 后将新行改为 S1），确认应用后编码归属更新到新项，保存刷新后仍有效。原项仅改名但仍存在时，其旧编码继续保留占用。复用编码不恢复旧行列的内部 ID、答案或按内部 ID 绑定的条件；按该编码编写的引用会读取新项。

## 显示代码的表达式合同

更新于 2026-10-23。选项、矩阵行和列的显示代码使用同步布尔表达式，例如 `Q1.isSelected("A1")`，也可读取 `context.formulas` 中的条件变量。只接受 boolean 返回值，不将数字或字符串转换为真假；代码不能修改答案、跳转或发起网络请求。留空表示不增加显示限制。编号审核会同步检查和更新表达式中的静态编码引用。

## 分组编辑与区间选择

更新于 2026-10-23。打开“选项分组”后，点击已有分组名称即可进入编辑视图，修改名称、成员和组内设置；保存修改后返回列表，取消则放弃本次表单草稿。编辑保留原分组和成员身份。

新增或编辑分组时，点击“区间选择”，再依次点击起点、终点，包含两个端点的可选条目都会选中。支持从后往前选择，保留原有选择，跳过其他分组已占用的条目。完成后可以继续选下一段；点击“退出区间选择”恢复普通勾选和取消。区间按当前编辑列表顺序计算，与选项编码和答题页的随机排列无关。

## 显示逻辑

点击题卡的“题目逻辑”按钮，仍打开包含“显示逻辑／跳转逻辑／校验逻辑”的同一个弹窗，默认进入显示逻辑。显示页直接提供编号、名称、显示代码表格；切换页签保留草稿，保存时整体检查并应用，显示表达式或其他规则错误时不部分应用。

更新于 2026-10-24。在有选项的题目中打开“选项属性 → 显示逻辑”，逐项编辑编号和单行显示表达式。支持普通及分组选择、排序、多项填空、多项评分、轮播选项与矩阵行列。矩阵窗口只展示当前“行选项／列选项”Tab 对应的项，占位角不参与设置。每条表达式只控制所在项，不控制其他选项或整个题目。“显示逻辑”与“批量修改选项编码”并排显示，并与上方配置项留出间距；前者的红色角标统计已保存的非空显示代码项数，未配置时隐藏，矩阵按当前轴分别统计。

可从 Excel 复制一列单元格，在“显示代码”列的目标单元格粘贴，按当前窗口顺序从该行向下覆盖；从首行粘贴与选项数量一致的数据即可替换整列。空白单元格会清空对应显示代码，粘贴范围外的行保留原值。Excel 的引号转义会还原为原始表达式，末尾用于分隔的换行不会增加一行。只接受单列；多列或超过当前轴剩余行数时整批不应用并显示原因，不会截断、跨到另一轴或新增选项。普通单行文字粘贴保留输入框的选中替换行为。粘贴只修改弹窗草稿，仍需点击“保存”通过语法和引用检查；关闭窗口会放弃草稿。

填写 `Q1.isSelected("A1")` 或 `context.formulas.allowed` 等同步布尔表达式，不需要写 `return` 或完整函数。返回 `true` 时允许显示，`false` 时隐藏；留空不增加限制。其他逻辑或关联条件已经隐藏的项，不会因这里返回 `true` 重新显示。动态矩阵行沿用来源行的显示条件。

点击“保存”先检查语法和编码引用；编号有变更时继续进入已有的整卷引用审核，确认成功后统一应用。取消窗口或审核不会保存部分修改。代码报错、返回非 boolean 或发生计算循环时，公开答题明确报错并阻止继续与提交。隐藏后会清除该项对应的答案和附带文本，再次显示不会恢复旧答案；矩阵行清除整行，矩阵列清除所有行对应的单元格。服务器根据发布问卷中的代码复核最终提交，不接受隐藏项答案；后端自动勾选重新加入的隐藏项会先被清除，避免将正常答卷误判为非法提交。

## 分组弹窗关闭保存

更新于 2026-10-23。关闭“选项分组”时，系统会保存已创建的分组、已点击“保存修改”的成员设置，以及分组排序和开关等即时修改。右上角关闭、Esc 和底部关闭执行相同保存流程。正在编辑但未确认的表单不会自动提交，关闭成功后放弃。

关闭保存与顶部“保存”一样保存整份问卷，可能同时保存其他已确认的设计修改；没有待保存修改时直接关闭。保存期间不能重复关闭或编辑。保存失败时弹窗保留，显示错误原因，可重试；未确认表单草稿也会保留。

## 显示条件运行合同

本题、选项和矩阵行列的显示代码采用严格布尔表达式：空白不增加限制，false 追加隐藏，true 不解除父题或关联限制。代码可读全卷答案以及由答案、常量和确定性纯函数计算的变量；不能读取系统环境、实时进度、时间、随机数或可变运行变量，不能写答案、请求网络或跳转。变量的间接依赖同样检查。计算错误阻止推进，不被当作 false。

旧 visibility 规则卡及跨题显隐配置会提示 LEGACY_DISPLAY_RULE，需要明确清除后重新编写；不会自动迁移或丢弃源码。程序合同升级后，旧发布问卷需重新保存、发布，前端与后台脚本服务须使用配套版本。

## 图形生成与组内批量编辑

“题目逻辑 → 显示逻辑”和选项属性中的“显示逻辑”使用同一张表：第一行是本题，下面是选项或当前矩阵轴。无选项题也能编辑本题显示条件。每行右侧独立的“图形化编辑”列提供编辑按钮，与显示代码输入框分列展示。点击按钮新建条件草稿，不从现有代码反显；“生成并填入”在已有代码时确认覆盖，取消保留原代码和图形草稿，外层保存后才应用。编号及显示表达式一起审核和保存。

选中问卷大纲组后，“批量设置显示逻辑”只修改组内各题自身条件，与单题第一行同步，不是组准入，不向选项复制代码。Excel 单列粘贴只在本题、选项或当前矩阵轴的各自区域内覆盖；空白可清空，多列或超界整批拒绝。旧规则可在单题表格明确确认清除，跳转、校验、关联和自动勾选保留。
