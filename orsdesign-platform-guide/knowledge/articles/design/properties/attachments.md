# 题目附件

题目附件供答题者为某道题上传补充材料。文件与题目的文字、选择等原始答案分别保存。

## 使用前提与入口

在问卷编辑工作区选中题目，进入右侧**基本属性 → 题目附件**。默认关闭；开启后显示附件设置。描述、分页、轮播图及历史独立上传题不显示此设置。

## 操作步骤

1. 开启题目附件，按需要设置图片限制、大小范围、最少附件数与同名附件规则。
2. 保存问卷后进入测试或公开答题页，填写原题答案并上传附件。
3. 已上传附件可打开或移除；启用缩略图后显示图片预览。附件上传完成后再继续或提交。

## 按钮与设置

| 设置           | 默认值 | 作用                                               |
| -------------- | ------ | -------------------------------------------------- |
| 题目附件       | 关闭   | 在答题控件下方展示附件上传入口                     |
| 允许不上传     | 关闭   | 开启后不检查最少附件数；已上传文件仍须满足其他限制 |
| 仅图片         | 关闭   | 只接受图片文件，服务器检查实际文件内容             |
| 显示图片缩略图 | 关闭   | 为已上传图片提供缩略图和预览                       |
| 最小大小（MB） | 0      | 单个文件的最小大小，不接收空文件                   |
| 最大大小（MB） | 100    | 单个文件的上限，最高 100MB                         |
| 最少附件数     | 1      | 未允许不上传时，继续和提交前需达到此数量           |
| 允许同名附件   | 关闭   | 同一道题默认不能上传名称相同的附件                 |

## 结果与限制

此处 MB 按 1024 × 1024 字节计算，边界值包含在允许范围内。**仅题目附件开放单文件最大 100MB**，问卷封面、富文本等其他上传保留原有限制。上传和最终提交均由服务器校验，失败时不加入已上传列表，可重新选择文件。

附件在同一答题会话内随本地草稿恢复；重新建立会话时需重新上传，清空草稿时一并移除。题目因条件隐藏或跳转清空答案时，附件记录也会清除；重新显示不会恢复。附件不替代原题必答答案，也不改变公式、条件与题目脚本读取到的答案值。答卷详情和附件导出沿用原有附件展示链路。

编辑区的本地预览展示附件配置，不实际上传文件，也不要求满足附件数量；完整上传验证请使用问卷测试或公开答题页。已上传但尚未提交的文件只代表上传成功，不代表问卷已经提交。
