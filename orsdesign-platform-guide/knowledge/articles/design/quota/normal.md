# 普通配额

普通配额将一个或多个选择题选项分别作为检查点。每个检查点独立设置目标与浮动量。

## 使用前提与入口

配额管理 → 普通配额。可用来源按当前列表为单选、多选、下拉、图片多选及规范化后的可用选择题。

## 操作步骤

1. 新增普通配额组，点击编辑填写组名。
2. 点击添加检查点，在树中勾选具体题目的选项并确认。
3. 为每行填写非负整数目标（空白表示不限额）和正整数浮动量；新加入的检查点默认目标10、浮动量2。
4. 保存组，确认完整后点击启用，等待配置生效。
5. 刷新进度或转到配额进度页核对各检查点。

## 按钮与设置

| 名称         | 位置       | 作用与结果                             | 可用条件                           |
| ------------ | ---------- | -------------------------------------- | ---------------------------------- |
| 新增普通组   | 配额工具栏 | 增加待编辑组行                         | 空组可保存为禁用草稿               |
| 组名         | 编辑窗口   | 标识此组用途                           | 不能为空                           |
| 添加检查点   | 编辑窗口   | 打开题目选项树                         | 题目有可用选项                     |
| 确认检查点   | 选择窗口   | 生成每个选项的独立行                   | 保留已有相同检查点的目标           |
| 目标／浮动量 | 检查点行   | 设置完成容量及备份余量                 | 目标非负整数或空白；浮动量正整数   |
| 保存         | 编辑窗口   | 写入独立配额草稿；配额已启用时触发激活 | 空组保存为禁用草稿，启用需完整配置 |
| 启用／关闭   | 组行       | 更新运行配置与归类                     | 维护中禁用                         |

## 结果与限制

勾选题目多个选项会产生多行检查点，不是“任意命中这些选项共用一个总数”。多选答卷可同时命中多行，最终分类需满足全部命中条件。取消编辑不保存待新增组。

## 检查点与不限额

每行的条件来源与检查时机独立：检查点列可选择最多三道题，读取的条件题目不因此改变。不设置显式检查点的历史配置继续按条件依赖推导；显式清空单元检查点表示只在最终提交检查。自动完成题和合页也经过相应检查。尚未作答的普通否定条件不作为已经命中。

目标留空表示不限额，不会转换为0；浮动量保留但不限制不限额单元。目标N、浮动量1时可收N条正式及1条备份，之后判满。本次椰子水还原采用浮动量1，其他问卷默认值仍为2。
