# 级联题

级联题逐层选择分类路径，可直接粘贴数据、导入文件或使用我的数据资源。

## 使用前提与入口

问卷编辑 → 左侧题型面板。点击题型加入当前选中题之后，或拖到画布指定位置；选中题卡设置右侧属性。结构锁定时先停止收集。

## 操作步骤

1. 打开“配置级联数据”，在本地输入页粘贴结构化数据并应用。
2. 或导入 JSON、XLSX 或 XLS 文件，创建可复用资源；也可从资源列表选择已保存的数据。
3. 检查当前层级数和预览，保存问卷。
4. 测试选择上一级后下一级候选是否正确变化。

## 按钮与设置

| 名称           | 位置     | 作用与结果                       | 可用条件                       |
| -------------- | -------- | -------------------------------- | ------------------------------ |
| 配置级联数据   | 题目属性 | 打开数据设置窗口                 | 选中级联或兼容城市题           |
| 应用本地数据   | 本地页签 | 解析并写入本题级联结构           | 至少一个有效节点               |
| 选择文件／导入 | 文件页签 | 解析文件并创建可复用资源         | 需有效文件；保存失败保留原配置 |
| 拆分层级       | 导入页签 | 当前尚未实现，开启时明确拒绝导入 | 请关闭后导入完整树             |
| 资源列表／刷新 | 资源页签 | 加载并选用级联资源               | 服务器资源可读取               |
| 逐级选择       | 答题区   | 保存所选路径                     | 数据加载完成                   |

## 文件格式（2026-10-15）

JSON 使用带 `value`、`label` 与 `children` 的树，也支持现有代码／名称树的规范化。选项编码在整棵树内不能重复。Excel 使用第一个工作表，无表头，每行是一条完整路径，每列是一级；尾部空白忽略，中间缺级会拒绝。重复路径合并，同名节点在不同分支得到稳定的不同编码。

文件最多 10 MiB、10 级、10000 个节点。成功后创建服务器资源并应用到当前题；非法文件或资源保存失败均保留原配置，不以本地回退冒充成功。

## 结果与限制

资源加载失败会提示，不应假定下级无选项就是问卷设计为空。省市预设使用内置地区数据；自定义行业、专业等需核对实际来源。

## 城市地区分类 area

内置“中国省市”的每个市级节点，以及“中国省市区”的每个市级、区县节点均有 `area` 文本属性。省级节点不设置此属性；区县继承所属市的分类，萧山区为“华东新一线城市”，当涂县为“其他”。

| 城市 | area |
| --- | --- |
| 上海 | 华东一线城市 |
| 杭州、南京、苏州、合肥、宁波 | 华东新一线城市 |
| 广州、深圳 | 华南一线城市 |
| 珠海、佛山、东莞、南宁、海口、福州、厦门 | 华南新一线城市 |
| 武汉、长沙、郑州 | 华中新一线城市 |
| 其余市及区县 | 其他 |

脚本通过 `Q1.area` 读取当前选择最末级节点的分类。选择到城市一级即可读取该市分类；未答或节点无属性时为 `null`。自定义 JSON 可以为节点配置同名属性。结果数据的01和非01 Excel 在每道城市题的路径列后生成独立的 `题目编码__area` 列，详见[Excel 导出](http://design.ors-cn.com/agent-help/articles/data/export.md#城市题地区分类)。

## 取值与可用函数

以下以本题实际编码为 `Q1` 为例，`Q1` 与 `context.questions.Q1` 等价。`Q1` 本身是题目对象，公式应返回具体字段或计算结果。字段支持表中的驼峰写法及大写协议名（如 `value`／`VALUE`、`hasAnswer`／`HAS_ANSWER`）；方法名区分大小写。

| 写法 | 含义与返回值 |
| --- | --- |
| `Q1.value`／`Q1.values` | 所选路径节点值；一级时 `value` 为单值，多级为数组；`values` 始终为数组。 |
| `Q1.answer`／`Q1.answers`／`Q1.label` | 当前通用协议把节点值转换为文本，不会自动换成级联节点 label。 |
| `Q1.area` | 所选最末级节点的地区分类；资源无 area、路径不匹配或未答时为 `null`。 |
| `Q1.hasAnswer` | 是否存在路径答案，不表示路径已达到必需层级。 |

通用身份字段：`Q1.id` 为内部 ID，`Q1.code` 为题目编码，`Q1.type` 为内部题型。`Q1.isShow` 仅在运行器提供显隐快照时可读；缺少快照会报错，自动选择条件禁止读取。

未答时，`value`／`answer`／`label` 为 `null`，答案数组为空，`hasAnswer` 为 `false`；分数 `0` 不能单独用来判断是否作答。`CASCADE` 与 `CITY` 共用上述接口；通过 `values` 按路径层级读取，或用原生 `join` 拼接。级联节点不是普通选择项，不能用 `select()` 获取路径，也不能假设 `options` 含整棵级联树。

### 可用方法与写入限制

本题没有普通选择项：`Q1.select()`、`Q1.unSelect()` 返回 `[]`，`Q1.isSelected("A1")`、`Q1.unSelected("A1")` 返回 `false`。这些查询不能代替本题的答案读取。

当前未开放本题的 `setValue`、`setSelection`、`selectOption`、`deselectOption` 或 `clear` 写方法。不能直接给 `Q1.value` 赋值；返回数组或对象也只读，不会回写答案。

### 计算示例

假设本地级联树中浙江节点值为 `zj`，其子节点杭州值为 `hz`、area 为“华东新一线城市”，当前路径为 `["zj", "hz"]`。在变量素材中选择 JavaScript 函数模式、结果类型“对象”：

```js
function compute(context) {
  return {
    path: Q1.values,
    leaf: Q1.values.at(-1) ?? null,
    area: Q1.area,
    joined: Q1.values.join(" / ")
  };
}
```

预期：

```json
{
  "path": [
    "zj",
    "hz"
  ],
  "leaf": "hz",
  "area": "华东新一线城市",
  "joined": "zj / hz"
}
```

完整参数与阶段说明见[变量参考](http://design.ors-cn.com/agent-help/articles/design/conditions/variables.md#题目维度全表)和[函数参考](http://design.ors-cn.com/agent-help/articles/design/conditions/functions.md)。
