# 公式编辑器操作

公式把题目答案、系统变量和函数组合成计算变量，可被条件、逻辑或文字引用使用。

## 使用前提与入口

问卷设计 → 条件设置（变量素材）。预发布及正式收集锁定时不可编辑。

## 操作步骤

1. 点击新增变量，在中间编辑区设置变量标识和显示名称。
2. 从左侧题目资源、系统变量或函数列表点击插入，在代码区补全参数。
3. 选择 JavaScript 表达式或 compute 函数模式，查看语法错误行；通过预览诊断运行参数、未知变量和循环依赖。
4. 点击保存配置；空公式或静态校验未通过时保存为草稿，通过校验后生效。选中其他公式前先保存当前编辑。
5. 通过模拟答题验证真实输入下的计算结果。

## 编码联想中的题目与选项文本

在代码区输入题目编码（如 `Q1` 或 `context.questions.Q1`）时，联想列表会在编码旁显示对应题目文本。输入 `Q1.isSelected("`、`Q1.unSelected("` 或 `Q1.select().includes("` 等选项参数时，会提示该题目的选项编码及选项文本；相同编码按所属题目区分。

使用方向键选择、Enter 确认，或点击联想项后，只补全编码，不会把题目或选项文本写进代码。列表中的长文本可在联想详情中查看完整内容；富文本内容以纯文本显示。题目钩子、显示／下一题代码规则和自动勾选编辑器复用此提示；自动勾选仍只允许引用前置题目。

## 平台控制操作与计算函数

更新于 2026-10-22。`show("Q3")`、`hide("Q3")` 是显示逻辑操作；`goto("Q3")`、`end()`、`complete()`、`full()` 是下一题逻辑操作。它们按阶段出现在相应代码框的联想中，目标字符串支持题目编码与文本提示。

这些操作不属于计算函数目录，不能用于计算变量、自动选择、渲染逻辑或答案校验。请在[题目逻辑代码框](http://design.ors-cn.com/agent-help/articles/design/logic/visual.md#代码逻辑简写)中使用；参数和执行规则见[逻辑操作简写](http://design.ors-cn.com/agent-help/articles/design/logic/dsl.md#逻辑操作简写)。

## 结果与限制

空公式、语法错误、函数入口不符合约定，或静态引用校验失败的变量显示“草稿 · 未生效”。草稿保留源码并可保存、刷新后继续编辑，只在条件设置中可见；不进入实际程序、下载文件或其他页面的可选变量目录。修正并保存后自动恢复生效，变量 ID 和键名保持不变。

依赖草稿变量的静态公式也暂不生效。已有图形规则或手写脚本继续引用草稿变量时会报告缺失引用，需要修正引用或完成变量；不会使用旧值、零或空值代替。运行中才发生的错误（如特定输入引发异常、动态引用失败、循环或超时）仍明确报错，不作为草稿静默忽略。

编辑器中的公式诊断不代表所有受访者输入都有效。区分“未作答”和合法的0，不要依赖显示占位数值。函数精确定义、维度与示例见参考文章。

## JavaScript 写法

表达式示例：`SUM([1, 2, 3])`。函数模式允许辅助声明：

```js
const weight = 2;
function compute(context) {
  const values = Q1.select();
  return { count: values.length, weighted: values.length * weight };
}
```

支持 let/const/var、数组、对象、闭包、循环、解构、展开、模板字符串和 try/catch。变量结果通过 `context.formulas.total` 读取；依赖按实际读取追踪，循环依赖明确失败。返回必须是可保存 JSON，不能含函数、循环引用、NaN 或 Infinity；Date、Map、Set 等可在内部处理，返回前转换为普通值。

变量是可重复纯计算，不请求网络，不读取当前时间或随机数。跨题状态通过钩子的 vars 效果保存；不要依赖普通 JS 声明跨执行保留。自动勾选所用公式进一步限制为前题答案及纯公式，不依赖运行 vars 或系统环境。

全部问卷使用新语法。旧 and/or/not、幂及链式集合写法必须通过结构迁移转换或人工重写；离线工具可提前生成逐项报告，执行失败不会回退旧语言。

## 第一阶段执行约束

变量显示名称可修改，已被引用的变量键和稳定 ID 不允许直接替换；删除时先移除引用。图形规则按稳定变量 ID 读取结果，脚本使用 `context.formulas.<变量键>`。计算失败显示变量 ID、名称和错误，不当作合法 null。旧全局 logicScript、surveyDslContent 和 dwDslAst 保留原始数据但不参与计算；题目图形规则仍生效。

代码补全与运行器共用题目能力目录：变量和自动勾选仅提示读取，答案校验仅增加错误提示；渲染与下一题逻辑可提示适用题型的受控写方法。题目编码冲突时使用 `context.questions["编码"]`，`ors` 下只提示集合便捷函数。打开自动勾选代码不会转换或覆盖已有源码；语法错误按实际行列定位。

## 变量素材与计算预览（2026-10-15）

条件设置只提供数据读取、处理和变量定义。可为变量声明数值、文本、布尔、数组、对象或空值类型；自动推断只根据源码中的明确字面量推断，不执行作者代码。类型决定图形条件可选运算符。保存保留类型、插槽状态和未知扩展字段。

变量键按原样引用：键为 `$total` 时写 `context.formulas.$total` 或 `context.formulas["$total"]`；键为 `total` 时写 `context.formulas.total`。新建变量默认采用 `var1` 等不带 `$` 的键。被引用后可改显示名称，不能直接改键或删除；页面列出引用路径。

“计算预览”接受以稳定题目 ID 为键的样例答案 JSON，例如 `{"question-id":"18"}`。预览只运行当前变量及其依赖，不保存问卷、不执行自动勾选或题目钩子。结果显示实际读取的变量；合法 `null` 与计算失败分开显示。修改源码、模式、键、类型、样例答案或问卷后，旧预览立即失效；切换或离开页面取消未完成预览。预览结果不能代替真实答题回归。

打开变量和应用示例不会调用旧语法迁移。`ISIN`、`NOTIN` 保留已有直接函数合同，`ors.isin`、`ors.notin` 使用各自的数组合同。日期示例的 `context.variables.PARAM.asOf` 需由受控参数显式提供；变量不能调用隐式当前时间函数。

## 全局对象与纯计算隔离

原生全局对象及其原型只读，包括异步函数和匹配迭代器的共享原型；不能通过 `globalThis`、`Math` 或原型属性向变量传递钩子临时状态。普通局部变量、数组、对象、闭包和类可按标准 JavaScript 使用；数组 `push`、`map` 等行为不变。跨题业务状态仍通过钩子的 `context.vars` 显式管理，纯变量与自动勾选不能读取这类状态。


数组可使用 `Q1.select().isin("A1", "A2")`、`.notin(["A3"])`、`.any("A1")`，普通数组及 map/filter 结果也支持。编辑器会提示这三个方法与 isIn/notIn 别名。链式沿用 orsold 的严格匹配；现有直接函数、ors 帮助函数和矩阵对象方法的类型转换合同不变，详见[集合函数合同](http://design.ors-cn.com/agent-help/articles/design/conditions/functions.md#数组链式集合判断)。

## 大问卷的纯表达式复用

更新于 2026-10-25。已有纯表达式缓存支持任意规范题目编码（如 `SQ14`、`D1`），也支持 `context.questions["SQ14"]` 和明确矩阵轴的静态读取。无公式定义且能够证明为静态题目读取时，隔离运行器仅接收这些题目快照；其余情况保留原输入。全卷每条表达式仍按原顺序处理。只在依赖题目的只读快照、源码及问卷身份未变化时复用；相关答案变化会失效。默认缓存最多 512 条、16MB，超出时淘汰旧条目。系统上下文、动态寻址、函数体、生命周期钩子及带宿主写入／网络能力的调用不复用。仍执行现有全卷稳定计算，不改变显隐、预填、校验和跳转的执行顺序。

较大的问卷在保存／发布时需要编译及引用审核。私有服务对这两项静态操作提供最多 10 秒的传输等待；答题自动选择仍保持 2 秒传输和原有脚本执行时限。

私有服务的大问卷审核需要容纳完整程序及属性来源索引。系统 1.254（2026-10-25）将宿主默认 Node heap 调整为 384 MiB、容器上限调整为 1 GiB，源构建、产物镜像与隔离 QA 使用相同配置；原部署需要同步更新资源配置。作者代码仍在独立的 64 MiB VM 内运行，执行时限及读写权限不变。该资源调整不改变全卷稳定计算，也不代表已验证任意规模或所有答案组合。

既有权威编译缓存的总字节上限同步为 64 MiB，最多 16 条；大于上限的单个程序不缓存，显式更小的配置仍生效。复用只针对完全相同的权威定义，每次读取仍返回独立程序并校验发布指纹。

数组还支持 `Q1.select().notinclude("A1", 1)`，语义为原生 `includes` 取反；可选第二参数是起始下标。没有直接函数或其他大小写别名，详见[notinclude 合同](http://design.ors-cn.com/agent-help/articles/design/conditions/functions.md#数组-notinclude-方法)。
