# 问卷编辑工作区

设计页由顶栏、左侧面板、中间画布和右侧属性区组成。先选中题目，再在右侧查看该题可用的属性。

## 使用前提与入口

我的问卷 → 问卷设计 → 问卷编辑。预发布、正式收集中会锁定答题结构。

## 操作步骤

1. 在左侧“题型”点击或拖动题型到画布；点击添加通常插在当前选中题后。
2. 在画布编辑问卷标题、说明、题干、选项；打开设计页时所有题目默认展开；题卡上的折叠／展开按钮可单独控制每一题，切换选中题不会自动折叠其他题，重新打开或刷新设计页恢复默认展开。
3. 在右侧基本属性、选项属性、题目属性设置当前题；点击属性说明旁的箭头可收起或展开整个属性区，进入设计页时默认展开。
4. 点击保存，打开模拟答题验证；正式收集中的结构改动须先停止收集。

## 按钮与设置

| 名称       | 位置             | 作用与结果                         | 可用条件                   |
| ---------- | ---------------- | ---------------------------------- | -------------------------- |
| 题型       | 左侧页签         | 选择题型模板                       | 接口失败可显示本地备用题型 |
| 大纲       | 左侧页签         | 定位题目、管理分组和批量编码       | 已有问卷                   |
| 题库       | 左侧页签         | 将资源题目复制入本问卷             | 选择有效题库               |
| 折叠／展开 | 题卡工具栏       | 单独收起或展开当前题内容           | 选中题目                   |
| 题目逻辑   | 题卡工具栏       | 编辑本题显隐或跳转规则             | 支持该题目标配置           |
| 多题测试   | 画布顶部         | 勾选多题组成临时预览               | 无可测试题时禁用           |
| 全选／清空 | 多题测试弹层     | 批量维护待测题目选择               | 仅临时测试选择             |
| 选择区间   | 多题测试弹层     | 依次点击两个端点，选中其间全部题目 | 再次点击按钮退出区间模式   |
| 开始测试   | 多题测试弹层底部 | 新窗口打开所选题目预览             | 至少选一题；不保存正式答卷 |
| 全局逻辑   | 画布顶部         | 导航到独立逻辑引擎页，保留规则计数 | 问卷结构未锁定             |

## 切换内容编辑与外观设计

切换后导航立即更新，工作区在首次加载页面或问卷时显示加载状态；等待期间仍可切换其他入口。加载失败可点击“重试”。同一问卷内返回内容编辑时复用已打开的页面和问卷，保留选中题、面板及滚动位置，不重复读取整卷。刷新、离开工作台或切换问卷后重新初始化。

页面保活不代替保存；请继续使用保存与自动保存确认修改已提交。

## 结果与限制

多题测试按原问卷顺序组成临时预览。区间选择可以反向选择，也可以连续选多段；“全选”“清空”会取消尚未完成的区间起点，退出区间模式会保留已选题目。涉及未选题目的依赖需用整卷模拟再次验证。画布中的禁用输入、示意评分等是编辑预览，填写验证请用测试入口。题卡不再提供题目属性快捷按钮，选中题目后直接在右侧属性区设置。工作区顶部不再提供语言切换和设置语言入口。
